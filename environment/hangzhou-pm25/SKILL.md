# 杭州 PM2.5

回答三个问题：现在 PM2.5 有多少，接下来几天大致怎么变，哪些天气条件可能影响它。使用自带脚本取数和计算，用大白话解释结果。

## 调用

将 `<skill-dir>` 替换为本 SKILL.md 所在目录的实际路径。在 Windows 使用可用的 `python`，在其他平台可用 `python3`。需要 Python 3.10+，无需安装第三方依赖、配置 API Key。

```bash
python "<skill-dir>/scripts/hangzhou_pm25.py"
```

默认查询杭州主城区参考点（30.2741, 120.1551），提供**含今天的五个北京时间自然日**。若用户只要近期几天，可传 `--days 1` 至 `--days 5`。

需要进一步组织回答时读取 JSON，不要从网页另抄一套混合口径的数据：

```bash
python "<skill-dir>/scripts/hangzhou_pm25.py" --format json
```

用户需要文件时指定输出目录，会同时生成 `report.json` 和 `report.md`：

```bash
python "<skill-dir>/scripts/hangzhou_pm25.py" --output-dir "<output-dir>"
```

其他参数、来源和解释规则见 [数据来源与输出口径](references/data-sources.md)。排查数据缺失、回放旧批次、讨论标准或模型可靠性时读取该参考文件。

## 如何回答

- 先说当前浓度及实测时间，再用两三句话说未来几天较高或较低、什么时候值得再查。需要时附每天数值表。用户要大白话时，把“边界层低”解释为“污染物向上散开的空间较小”。
- `current.kind=observation` 是参考点周边 25 km、同一最新有效小时的站点自算均值，**不是官方全市均值**。可以用 `observations.stations` 说明站点差异。`model_estimate` 必须说“模型估计，非实测”。`current=null` 就说明当前数据缺失。
- `daily.mean_pm25` 是当天有效小时的模型均值，不是实测。`valid_hours<24` 时注明覆盖不足；今天全天值含已经过去的时段，剩余时段看 `remaining_mean_pm25`。五个日期不代表从现在起完整 120 小时。
- 只引用 `factors` 及其 `weather` 数值解释可能影响，不把天气线索说成已经确定的污染来源。温度、风向没有固定好坏；没有上风向污染输入就不能声称污染从某地吹来。
- 所有浓度单位为 μg/m³。脚本不换算 AQI 或污染等级；不能把 PM2.5 一个指标说成综合空气质量，也不能把它说成“对某人绝对安全”。
- `partial` 表示仍有数据可用，应说明重要缺项；退出码 1 表示没有可用 PM2.5，仍可读取生成的缺失报告。退出码 2 是参数、输入或文件错误。先检查错误，不编造数值。
- 保留中国环境监测总站、CAMS / ECMWF 和 Open-Meteo 的来源署名及必要链接。说明这是区域模型的大致预期，尚未经过杭州本地精度回测，不输出伪造的置信度。

本 skill 只查询和生成报告。安装发布、定时执行、推送到其他服务应按用户实际请求另外处理。
