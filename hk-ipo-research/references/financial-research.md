# 实时全网财务研究

每次研究都重新检索公开网页。不要把 HKEX PDF 作为财务数据的默认入口，也不要因为 HKEX 访问失败就把财务字段写成 `未找到`。

## 检索后端：SearXNG 自托管元搜索

`web_search`（或任何 agent 自带的网页搜索工具）如果配置走 SearXNG 自托管实例（`SEARXNG_URL`，默认期望 `http://127.0.0.1:8888`），引擎组合通常是**国内引擎**（百度 / 搜狗 / 360 / 必应中国）——常见的内网部署选择。

### 启动前先确认 SearXNG 在不在

不要假设 SearXNG 已经跑着。先 curl 看：

```bash
curl -sS -m 3 -o /dev/null -w "%{http_code}\n" "${SEARXNG_URL:-http://127.0.0.1:8888}/"
# 200 = 在跑
# 000/timeout = 没启
```

**找不到再启动**（如果机器上有 `/home/ohyes768/searxng/docker-compose.yml`）：
```bash
cd /home/ohyes768/searxng && docker compose up -d
```

如果 agent 不知道 SEARXNG_URL，问用户；不要自己拍。

### 引擎可达性边界（典型内网部署）

这种部署所在的机器通常**没有国际网出口**，所以：

- ✅ **中文媒体命中率高**：新浪财经、东方财富、腾讯新闻、智通财经、格隆汇、36Kr、搜狐财经、界面、21 财经、公众号转载——基本能搜到
- ⚠️ **英文招股书 / HKEX PDF / 路透 / FT**：通常不可达，不要把"英文搜不到"当数据缺失；要立刻切到中文二手转载
- ⚠️ **AAStocks / ETNet**：HTTPS 偶通但经常 403 / timeout，作为可选补充，不要阻塞

**不要假设**你用的后端就是 SearXNG；如果 agent 配置走其他后端（DDG/Brave/Tavily 等），能力边界完全不同——遇到连续搜不到时，先确认 `web_search` 实际走的是哪个后端。

### 搜不到英文时的 fallback

1. 立即用**公司中文全称 + 股票代码**重搜（如 `拿森科技 02261.HK 招股`），中文媒体转载通常含数字摘要
2. 加 `site:sina.com.cn` / `site:eastmoney.com` 等域名限定，逼出财经媒体源
3. 加 `site:qq.com` / `site:sohu.com` / `site:163.com` 抓新闻门户转载
4. 拿不到招股书原文条款时，**如实写 `未找到（仅中文二手转载可得）`**，不要伪造数字

## 检索顺序

1. 优先使用 agent 的实时网页搜索能力发现来源，不先直连 AAStocks、ETNet 或 HKEX。用公司中文全称、简称、英文名、历史主体名和股票代码分别搜索。
2. 一次并行提交多组查询，不在单一站点上串行耗时。组合以下关键词：
   - `公司名 招股书 收入 净利润 毛利率`
   - `公司名 2023 2024 2025 营收 亏损`
   - `公司名 现金流 研发 客户集中度`
   - `公司名 基石 股东 保荐人 募集资金用途`
3. 若结果不足，追加定向查询：`site:finance.sina.com.cn`、`site:hk.stockstar.com`、`site:zhitongcaijing.com`、`site:gelonghui.com`、`site:sohu.com`、`site:36kr.com` 与公司官网域名。域名不可达时立即换下一个，不重复请求超过一次。
4. 打开并核对搜索结果正文，不把搜索摘要当唯一证据。正文被拦时，可用另一个转载同一招股资料的页面核验，但要标明二手来源。
5. 优先选择明确写明“据招股书/申请版本”的同期报道、发行人官网、保荐人或财经媒体深度稿；再用第二个独立来源交叉确认。
6. 若最终上市版尚未被媒体解析，可使用递表版或聆讯后资料集的公开摘要，但必须标注版本日期和“待最终版本核验”。

可用来源包括智通财经、财联社、新浪财经及其 IPO 专栏、证券之星、格隆汇、搜狐财经、36Kr、界面、21 财经、公司官网、投资机构官网及可信行业媒体。AAStocks、ETNet 只作为可选补充；超时、403 或空表时立即跳过。不要把来源名单当白名单；根据页面是否有明确数字、期间、币种和资料版本判断质量。

## 必取字段

- 最近三个报告期的营业收入、同比变化或复合增长率；
- 最近三个报告期的净利润或净亏损；
- 毛利率及变化；
- 经调整利润或亏损（若公司披露）；
- 经营现金流、现金及现金等价物；
- 前五大客户及最大客户收入占比；
- 研发开支或研发强度（科技、医药及制造企业优先）；

每个数字同时记录报告期、币种、单位、口径和来源。不得把 GMV、合同额、订单额当营业收入，不得把经调整利润冒充法定净利润。

## 交叉验证与缺失处理

- 收入与净利润/亏损属于发布 RSS 前的硬门槛：至少需要一个有明确期间和数值的可靠来源，并尽量用第二个来源核验。
- 毛利率、现金流或客户集中度至少取得一类有数值的质量指标；否则降低数据置信度并暂停 RSS 发布，继续检索。
- 来源数字冲突时列出两个版本、日期和口径，不擅自平均。
- 只有完成多组关键词、公司中英文名和至少三个独立域名的检索后，才能写 `未找到`，并列出查询词与已查来源。AAStocks 超时和 ETNet 403 只算两个失败源，不能据此结束研究。不得写“建议读者自行翻阅招股书”代替研究。
- `未披露` 只能用于来源明确表示没有披露该项目；检索失败必须写 `未找到`。

## 历史时点

做历史预测时，只采用预测截止点前已发布的网页。当前网页若没有发布日期、可能被后来覆盖，不能进入历史预测；按 `hk-ipo-backtest` 的未来数据隔离规则处理。
