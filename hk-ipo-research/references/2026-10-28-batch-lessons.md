## 1. 空批次：两个有效来源即可，失败不算否定

原任务报告 AAStocks IPO 主页面出现「暫時沒有公司正在招股」，并与新浪招股窗口过滤结果一致。

- 新浪候选发现正常完成、原始表格及日期解析完整且窗口过滤为 0，是交叉验证的起点。网络错误、空响应、解析失败不能折算成 0。
- AAStocks 提示需位于当前正常页面的招股中区域。检查抓取时间及页面日期（若有）、缓存迹象和正文；隐藏模板或脚本里出现同一句话不足以作证。
- `.HK` 行可能对应已截止、仅待上市的股票。逐行核对招股起止日期；截止日当天还需核对香港时间的截止时刻及券商安排。代码存在不等于仍可申购。
- 两个有效来源一致，可结束空批次确认；出现缺失、过期或冲突时，补查集思录招股窗口或发行人 / HKEX 具体公告。不能消除疑点则报告 `可申购状态未确认`，不要当作已确认无新股。

确认无新股后不生成报告、不推空 RSS。cron 是否输出一行回执遵循当前任务约定；交互式查询直接说明结果。

## 2. 行情空串与延迟上市分别判断

原记录提到个股行情空串、已上市对照股票有行情，并据此推断“未交易”。该推断证据不足。

- 对照正常只排除部分整体故障；个股空串也可能来自尚未开盘、停牌、参数错误或接口覆盖缺失。
- 延迟 / 撤回以发行人或 HKEX 的具体公告正文、发布日期和股票代码为准。新浪日期占位值、集思录状态和日历只是线索，公告首页及搜索摘要不能替代正文。
- 没有具体公告证据时写 `状态未确认`；尚未开盘时不能提前写首日收益，更不能把空串解释为延期。

## 3. 页面字段污染：隔离整行，不拿异常涨幅验证评分

原记录报告 AAStocks 上市表有代码与公司名称不符的行，并出现 `累计 -100%` 等值。“股票与窝轮复用模板”只是根因猜测，仍需原始 HTML 或结构化响应核实。

- `(@EC)`、`購`、`牛熊` 等词触发身份复核，不能仅靠词表排除真实 IPO。
- 名称与代码冲突时隔离整行，包括该行价格、暗盘及涨幅字段。先从独立来源确认身份和数值，再恢复使用。
- 对 `-100%`、空价格等值，检查价格基数、缺失值表示和收益计算口径；确认前标记 `待核验`，不纳入评分或回测。
- 复盘应分开事前预测、已核验结果与未知项。单一异常字段不能证明原评级正确，暗盘表现也不能替代首日收盘收益。

## 4. 搜索降级：空结果、引擎错误与页面错误分开记录

原任务报告 SearXNG 返回空结果，响应另含 `google cse timeout`，部分财经页面请求返回 500。

- 空结果本身不证明故障；宽泛查询与错误元数据用于诊断。一个引擎超时不证明所有引擎都不可用。
- 必要时切换其他搜索工具或公开 Bing 页面，以公司全称、代码和港股限定词减少歧义；遇到拦截或结构变化就换来源。
- 具体公告 / 文章正文才是证据。首页与摘要只用于导航，页面 500 只记当次请求失败。
- 降级方法统一维护在 [financial-research.md](financial-research.md#检索故障与降级)，不把某日故障写成永久禁用规则。

## 判断场景检查

| 输入场景 | 应有处理 |
|---|---|
| 新浪完整表为 0；AAStocks 无招股提示有效，仅有已截止待上市行 | 日期及来源有效性一致后确认空批次 |
| AAStocks 提示只在缓存 / 隐藏模板中，或有仍在招股的有效行 | 不采信该否定提示，补查并处理冲突 |
| 新浪请求超时或表格解析失败 | 状态未确认，不当作 0 只 |
| 搜索空结果，没有错误元数据 | 无匹配或原因未确认，不宣布后端已停 |
| 仅一个引擎 timeout，其他引擎状态不明 | 记录该引擎本次失败，必要时降级 |
| 开盘前个股空串，对照股票正常，无延期公告 | 不判定延期或首日收益 |
| 代码与名称冲突，同行涨幅 -100% | 隔离整行，核验身份及价格，不验证评分 |
