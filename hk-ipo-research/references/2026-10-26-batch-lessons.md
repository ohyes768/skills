## 三、关键新增发现

### 1. N = 0 时 SKILL 的 `[SILENT]` 与 cron 交付要求冲突（新增 PITFALL #38）

- SKILL.md 第 1 步写「N = 0 → 直接返回 `[SILENT]`」。
- 但本 cron job（用户 2026-10-16 显式配置，`deliver = origin`）的 prompt 写「N = 0 时 final response 只发一行：`【YYYY-MM-DD 港股打新】今日无新股可申购`」。
- **冲突后果**：若照 SKILL 返回 `[SILENT]`，cron framework 会**抑制投递** → 用户微信 / 飞书完全收不到消息，无法区分「任务没跑」和「今天确实没新股」。
- **裁决**：**cron prompt 优先**（更具体 + 用户显式设定）。N = 0 → 输出一行 `【2026-10-26 港股打新】今日无新股可申购`，**不返回 `[SILENT]`**。
- **不变的部分**：仍然**不生成 Markdown、不推送 RSS**（不推空文章这条不变）。
- **适用范围**：仅 cron 场景。交互式调用（用户直接问「今天有什么新股」）仍可返回 `[SILENT]`。
