# 实体经济强弱判断 Skill

## 触发条件

用户询问经济强弱、运行状态、评分、分析经济指标时自动触发。

## 核心能力

1. 从本地 CSV 数据文件读取最新月份四大指标数据
2. 基于评分体系计算各指标得分和加权总分
3. 输出结构化判断结论
4. 可选：构建 `macro_signal.json` 并推送到线上 macro 后端（`run_all.py --upload`，见下文「推送到线上 macro 后端」）

## 数据文件路径

所有数据文件位于统一输出目录 `finance-macro/output/entity-economy-skill/` 下（不入代码库）：

| 指标 | CSV 路径 | 关键列 |
|------|---------|--------|
| 制造业PMI | `output/entity-economy-skill/pmi_manufacturing/pmi_m.csv` | `制造业-指数` / `制造业-同比增长` |
| 非制造业PMI | `output/entity-economy-skill/pmi_non_manufacturing/pmi_nm.csv` | `非制造业-指数` / `非制造业-同比增长` |
| 工业增加值 | `output/entity-economy-skill/gyzjz/gyzjz.csv` | `同比增长` |
| 城镇固定资产投资 | `output/entity-economy-skill/gdzctz/gdzctz.csv` | `当月`（当月同比）/ `自年初累计` |
| 社会消费品零售总额 | `output/entity-economy-skill/consumer_retail/consumer_retail.csv` | `当月`（当月同比）/ `累计` |

## 评分体系

### 指标一：制造业PMI（权重 40%）

| 数值区间 | 得分 | 定性 |
|---------|------|------|
| > 53% | 80–100 | 经济过热 |
| 50%–53% | 60–80 | 偏热/稳健 |
| 49%–50% | 40–60 | 稳健/中性 |
| 47%–49% | 20–40 | 偏冷 |
| < 47% | 0–20 | 过冷 |

辅助规则：
- 新订单 > 生产 → +5分
- 生产 > 新订单且差距超过2个百分点 → -5分

### 指标二：工业增加值同比（权重 20%）

| 数值区间 | 得分 | 定性 |
|---------|------|------|
| > 7% | 80–100 | 偏热 |
| 5.5%–7% | 60–80 | 偏热/稳健 |
| 4.5%–5.5% | 40–60 | 稳健/中性 |
| 3%–4.5% | 20–40 | 偏冷 |
| < 3% | 0–20 | 过冷 |

### 指标三：固定资产投资累计同比（权重 20%）

| 数值区间 | 得分 | 定性 |
|---------|------|------|
| > 5% | 80–100 | 偏热 |
| 3.5%–5% | 60–80 | 偏热/稳健 |
| 2%–3.5% | 40–60 | 稳健/中性 |
| 0%–2% | 20–40 | 偏冷 |
| < 0% | 0–20 | 过冷 |

### 指标四：社会消费品零售总额同比（权重 20%）

| 数值区间 | 得分 | 定性 |
|---------|------|------|
| > 5% | 80–100 | 偏热 |
| 4%–5% | 60–80 | 偏热/稳健 |
| 2.5%–4% | 40–60 | 稳健/中性 |
| 1%–2.5% | 20–40 | 偏冷 |
| < 1% | 0–20 | 过冷 |

### 综合评分

**综合评分 = PMI得分×40% + 工业增加值×20% + 固投×20% + 社零×20%**

### 定性判断

| 评分区间 | 定性 | 说明 |
|---------|------|------|
| ≥ 80 | 经济过热 | 需关注通胀和政策收紧风险 |
| 60–79 | 经济偏热 | 扩张动能较强 |
| 40–59 | 经济稳健 | 中性，运行在合理区间 |
| 20–39 | 经济偏冷 | 下行压力显现 |
| < 20 | 经济过冷 | 需政策托底 |

## 工作流程

1. **确定目标月份**：取各指标 CSV 中最新一条记录的月份
2. **读取数据**：从各 CSV 读取最新月份的指标值
   - 注意：各 CSV 第一行即最新月份数据（降序排列）
3. **计算得分**：对每个指标按评分表换算得分
4. **计算加权总分**
5. **输出结构化报告**

## 输出格式

```
## 实体经济强弱判断 · {月份}

### 核心结论
[一句话定性判断]

### 综合评分
- **总分：{X}分**（{定性}）
- 制造业PMI：{X}分 × 40% = {贡献}
- 工业增加值：{X}分 × 20% = {贡献}
- 固定资产投资：{X}分 × 20% = {贡献}
- 社零：{X}分 × 20% = {贡献}

### 指标数据表

| 指标 | 最新值 | 环比变化 | 单项得分 | 判断 |
|------|--------|---------|---------|------|
| 制造业PMI | X | +/-X | X | X |
| 工业增加值 | X% | +/-X | X | X |
| 固定资产投资 | X% | +/-X | X | X |
| 社零 | X% | +/-X | X | X |

### 结构性解读
- **景气度**：PMI 及分项新订单/生产分析
- **生产端**：工业增加值分析
- **需求端（固投+社零）**：固投和社零分析，说明供需格局
- **供需要平衡**：供给端 vs 需求端的强弱对比

### 风险提示
[如存在结构性问题在此提示]
```

## 推送到线上 macro 后端（可选）

将最新指标转换为契约结构 `macro_signal.json`（`conclusion` / `data_date` / `total_score` / `details`）并推送，web 宏观界面每个维度右上角展示评分徽章。
对接契约见 `personal-web/.trellis/spec/guides/macro-signal-upload.md` 第 2.3.A 节。

**前置配置**：在 `finance-macro/.env`（不入库）配置：

```env
MACRO_SIGNAL_UPLOAD_TOKEN=<token> # 推送鉴权，来自 personal-web 根 .env
MACRO_SIGNAL_UPLOAD_URL=https://web.duomi77.cn:9443/api/macro/signal/upload
MACRO_UPLOAD_SSL_VERIFY=0        # NAS 自签证书场景跳过 TLS 校验（仅限内网自建服务）
```

**方式一：抓取+评分+推送一条龙**

```bash
uv run python scripts/run_all.py --upload
```

**方式二：分步执行**

```bash
uv run python scripts/build_macro_signal.py    # 按评分体系计算总分并构建契约结构
uv run python scripts/upload_signal.py --dry-run
uv run python scripts/upload_signal.py --verify
```

**内置规则评分**：`build_macro_signal.py` 按 SKILL.md 评分体系自动计算
（PMI×40% + 工业增加值×20% + 固投×20% + 社零×20%，
缺失指标按剩余权重归一化），
`total_score` 随推送上线。月度数据 `data_date` 落在 `YYYY-MM-01`；
上传前自动预检（skill/file 白名单、字段结构、数据新鲜度 45 天）。

## 注意事项

- PMI 为当月数据，工业增加值/固投/社零通常为上月数据，输出时注明数据对应月份
- 各指标发布时间不同，综合分析时以实际获取的数据月份为准
- 趋势重于单月，单月波动不主导结论
- 优先参考 PMI（先行指标权重最高）
