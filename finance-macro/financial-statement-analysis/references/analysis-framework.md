# Analysis Framework

财务分析规则与回查路径。事实层与计算层的完整合同见 [artifact-contracts.md](artifact-contracts.md)；提取规则见 [extraction-rules.md](extraction-rules.md)。

## 事实层约束（映射 financials.json 时）

- 默认分析合并口径；母公司数据单列，存在疑义时不自动替换。
- 集团净利润、归母净利润、扣非归母净利润分别记录，不得互换。
- 半年/前三季度累计值不能当单季；只有同口径累计齐备时才允许相减得单季，并标记计算来源。
- 利润表与现金流量表比较同比期间；资产负债表比较期末对期初时点，不标"同比"。
- 比较期采用本 PDF 披露的可比重述口径，不混用调整前后值。
- 原文报告值、脚本计算值、分析推断三者分开；缺失与零分开；不虚构精确置信度百分比，用"已核验 / 存在歧义 / 缺失"等状态。

## 计算解释约束（脚本已内置）

- 现金勾稽用现金及现金等价物，纳入汇率等披露调节项；不得用资产负债表"货币资金"替代。
- 净利润不等于留存收益增量（股利、重述、权益变动）；有现金流补充资料时优先按其完整项目桥接。
- 自由现金流是 `经营现金流 − 购建长期资产支付的现金` 的明示简化口径；不用投资现金流净额替代资本支出。
- 杜邦使用集团净利润、平均总资产、平均总权益，与公司披露的归母加权 ROE 分列，不伪装为同一指标。
- 基期或分母非正、接近零、平均余额缺失时脚本输出不适用及原因；必要时描述利润额变化或扭亏/转亏，不算增长率。
- 非全年数据不年化；缺少足够比较期不下"持续改善/恶化"结论。
- 容差按输入精度设定；勾稽冲突先查页码、列映射、合并范围、单位与附注解释，未解决标记数据冲突，不指控造假。

## 初始发现 → 回查路径

| 初始发现 | 下一步查证 | 结论要求 |
|---|---|---|
| 应收增长明显快于收入 | 账龄、坏账准备、客户集中度、信用政策、并表变化 | 区分扩张、结算节奏与回收风险 |
| 存货增加、毛利率下降 | 库存构成、跌价准备、产销与管理层说明 | 不把存货增加直接认定为积压 |
| 利润增长但经营现金流走弱 | 现金流补充资料、经营性应收应付、税费及一次性项目 | 解释利润与现金差异；资料不足则说明 |
| 货币资金与债务同时较大 | 受限资金、现金等价物、存款地点、利率与到期结构 | 结合可用资金和偿债期限判断 |
| 归母与扣非差异大 | 非经常性损益披露、补助、处置、公允价值项目 | 用披露分类，不把其他收益全等同非经常性损益 |
| 商誉、资本化或在建工程突出 | 减值测试、资本化政策、项目进度及后续支出 | 金额、解释和未验证项分别呈现 |

回查方式：`extract_sections.py --pages N-M` 定向补提取附注页，再经 `pack_context.py --stage analyze --pages N-M` 读取。**对影响核心结论的歧义最多两轮补提取**，仍未解决就保留不确定性并降级相关结论。

## 风险信号输出

每个风险项目输出四态之一，并附事实、可能解释和下一步关注点：

- **触发** — 有证据支持该风险存在或值得关注；
- **已检查未发现** — 查过对应证据，未见异常；
- **资料不足** — 本 PDF 未披露足够信息判断；
- **行业不适用** — 该信号不适用于该公司所属行业。

行业通用阈值只是待校准的筛查线索，不是自动定性规则；红旗数量不得换算造假概率；第一版不生成综合评分。关键审计事项不等于非标准审计意见；无保留意见中的持续经营事项仍需单列。

## 指标适用性速查

| 指标 | 适用条件 | 不适用时 |
|---|---|---|
| 同比增长 | 同口径两期、基期为正 | 描述绝对额变化或扭亏/转亏 |
| CFO/集团净利润 | 两者同期同范围 | 资料不足即说明 |
| 简化 FCF | CFO 与购建长期资产现金齐备 | 输出组成部分 |
| 简化 ROE / 杜邦 | 平均总权益、平均总资产可得 | 输出"平均余额不足"，不伪造期初数 |
| 存货/应收周转 | 非金融企业、平均余额可得 | 金融企业直接标不适用 |
| 应计比率 | 仅作筛查线索，不按阈值定性 | — |
