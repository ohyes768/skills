# 分析框架

- 默认合并口径。集团净利润、归母净利润与归母权益不得互换。
- 利润表、现金流量表比较上年同期累计；资产负债表比较期初时点，不称为同比。不年化季度或半年指标。
- 比率计算使用相同期间、币种、单位、重述口径；平均余额必须是目标期间期初与期末。
- 缺失、零、负数分别解释。基期非正时不使用同比百分比推断改善；现金与净利润均为负时不据比值判断盈利质量。
- 区分货币资金与现金及现金等价物；现金勾稽需要披露的完整调节项，缺项不假定为零。
- 结合收入、利润、经营现金流、资产负债变化解释盈利质量与偿债压力；毛利润为收入减营业成本。
- 风险标记分为触发、已检查未发现、资料不足、行业不适用。使用 metrics.json 的 red_flags，不沿用示例状态或把筛查当作造假结论。
- F10 合并三表不能证明审计意见、受限资金、关联交易、减值政策或业务变化原因。保留这些限制，分析推断明确表达为判断，不伪装成公司解释。
