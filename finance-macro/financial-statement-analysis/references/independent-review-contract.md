# 独立复核合同

正式 report 始终执行来源校验、输入预检、同源渲染、正文校验和独立复算。所有关卡通过且所需期间报表完整时才返回 verified。

| 检查 | 合同 |
|---|---|
| A1/A2 | 正文首节为核心结论且存在该节 |
| A3 | 核心结论三到五句 |
| A4 | 存在报表、比率、盈利、风险、数据质量章节 |
| A5 | 表格行列数一致 |
| A6 | 无未解析绑定 |
| B0 | 保存的指标公式、输入、状态与风险信号等于标准复算结果 |
| B1/B2 | statement 和表格行独立格式化后逐字匹配 |
| B3 | 从 input_fact_ids 独立复算 computed 指标，不信任已存数值 |
| C0 | 被使用事实是有效非空值 |
| C1 | 原始 F10 字段值一致；派生事实复算一致 |
| C2 | 同口径同期间重复事实一致 |
| C3 | 来源证券和报告期一致 |
| C4 | 不混入未标明的母公司口径 |
| D1 | 期初期末资产等于负债加权益 |
| D2 | 完整现金调节项可用时检查现金勾稽 |
| E1 | 数值带正确单位 |

来源校验还比较留档哈希、字段映射、事实完整集合及维度；正文与 claim 台账必须与输入的确定性渲染一致，任何无绑定数字或错误来源闭包均拒绝。

缺失指标不引用数值，not_applicable 记录原因。资料不足不能冒充检查通过。正式报告预算为初检加两次修复；失败根据集中问题修 report_spec，不修改脚本或产物绕过检查。
