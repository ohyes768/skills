# 银行、保险：接口取数与剩余缺口

## 默认可用：东方财富候选指标

本页用于银行/保险 E 需要补数时。先复用本次已有数据；需要结构化候选时调用一次：

```text
python3 <skill目录>/scripts/fetch_financial_candidates.py --stock <工作目录>/stock.json --as-of YYYY-MM-DD --cache-dir <工作目录>/api-cache --output <工作目录>/financial-candidates.json
```

`as_of` 为实际研究截止日，不改原 stock.json。脚本仅需 Python ≥3.12 标准库，不装
AKShare、pandas 或 HTTP 库，不处理 PDF。HTTP 默认每次12秒，最多两次请求；401/403/429
不重试，响应超过4MiB或分页未完整覆盖窗口则报错。失败退出2，错误写 stderr，不生成成功包。

输出文件包含第三方数值候选、源字段、原值、单位、查询URL、JSON行列定位、报告期、
披露/更新日期、原响应哈希与抓取时间。stdout 只打印文件位置、行数、缺口等简短回执。
不传 --output 时 stdout 返回整个候选包（有界的本年及前四年窗口，最多100行）。

| 项目 | 银行 | 保险 |
|---|---|---|
| 能取得的候选 | 加权ROE、总资产净利率、不良率、拨备覆盖率、三项资本比率、净息差、拨贷比、成本收入比 | 加权ROE、偿付能力比例、投资收益率、退保率、新业务价值；各公司/期间可缺值 |
| 仍需取得或核对 | 该银行完整适用资本要求、LCR/NSFR、集团口径、银行ROA定义及最新披露完整性 | 重要法人名单、各法人核心/综合偿付能力、风险评级、可比寿险/产险历史、准备金/资负匹配与集团覆盖 |

### 使用边界

1. **输出是候选包，不是行业评分包。** `packet_type=financial_metric_candidates`、
   `ready_for_scoring=false`；不能直接传给 --bank-data / --insurance-data。
   它减少逐项找数和抄数，不能单独保证 E 可评级。
2. 东方财富是第三方数据平台，不是公司官方披露。按 [银行](bank-financial.md) 或
   [保险](insurance-financial.md) 核对官方来源、期间、单位和集团/法人后，才填写原行业证据包。
   不将第三方URL改成一个未读的官方URL，不能把全部候选自动登记成已确认事实。
3. `SOLVENCY_AR` 仅输出 `solvency_ratio_unspecified`，不猜集团/法人或核心/综合类型。
   `ZZCJLL` 不能未经定义核对就认作银行年报资产收益率。NBV 原始人民币元换算为
   百万元，原值同时保留；不自动认定三年精算假设已对齐。半年/季度ROE不年化成年度。
4. 缺失/null不补0，合法零和负数保留。代码、名称或行业不匹配立即报错；重复报告期
   全部排除并提示。只使用查询窗口内且报告/披露/更新日期不晚于 as_of 的行。
   这仍不是历史版本数据库，不能声称已排除所有未来重述信息。
5. 调用记入本轮 financial 取证预算，复用同一候选文件，不按每个指标重新请求。
   无可用行是缺证；401/403/429或渠道停止应登记真实故障，不能换目录重试绕过预算。
   最终仍缺核心证据就 gap / E=null，已核实其他分项照常保留。
6. 最终报告按主 skill 来源表展示。第三方候选若用于背景必须标明第三方/待核对；
   若不能支持关键结论，只列具体待验证问题，不伪装成官方证据。

### 缓存与刷新

按完整查询URL隔离缓存，保存原始JSON响应、URL、抓取时点和SHA256；1小时内复用，
超期自动重新请求。`--refresh` 明确跳过缓存，失败保留旧文件但不返回旧结果冒充成功。
缓存损坏时报错，核对路径后显式刷新；不静默反复取数。缓存命中只说明复用了该次抓取，
不能证明远端尚未发布更近报告。新研究截止日会产生不同查询；重要新披露可主动刷新一次。

## 对齐最新财报期（例如三季报）

`--as-of` 是研究截止日；`--report-date` 是要核对的财报期末，二者不同。例如：

```text
python3 <skill目录>/scripts/fetch_financial_candidates.py --stock <工作目录>/stock.json --as-of 2026-10-28 --report-date 2026-09-30 --cache-dir <工作目录>/api-cache --output <工作目录>/financial-candidates.json
```

目标期取自实际已知的公司财报元数据或调用方明确要求，不能仅因日历已进入10月就认定
该公司已发布三季报，也不能把网页显示的数据抓取日当成财报期。dividend 后续可把已知
财报期作为该参数传入；本次没有修改 personal-web 调用端或新增公告发现接口。

回执与候选文件均含 `report_alignment`：

| status | 含义与处理 |
|---|---|
| matched | 目标期存在可用行；target_observation_index 指向该行，仅代表日期对齐，不代表数字/主体已核实 |
| missing_target | 接口没有返回目标期，不能把半年报当三季报；可能是尚未披露或接口滞后，单凭此结果不能断言是哪一种 |
| target_rejected | 返回过目标期，但因披露/修订日期或重复期间等问题未采用；不得退回旧期声称完成最新期核对 |
| not_requested | 未指定目标期，仅展示接口最新返回/可用期，不能宣称已核对公司最新官方财报 |

`latest_returned_report_date` 是原始响应中可识别的最新报告期，可能属于被排除的行；
`latest_usable_report_date` 是通过日期及重复检查的最新期。目标期缺失或被排除时，
`target_observation_index=null`，历史行仍保留供背景/年度历史使用，不自动替代本期。
若返回了比指定目标更近的报告，newer_report_returned=true，先核对是否需要更新目标。

- 目标日期须为有效季度末、不晚于 as_of 且处于查询窗口内，错误参数在请求前拒绝。
- 指定不同目标期只对同一份原始数据重新核对，不强制重新联网。明确有新公告而缓存
  尚未更新时，可在原预算内加一次 --refresh；未命中不能自动无限刷新。
- 三季报ROE等按源报告口径保留，不年化，不把前三季度累计当第三季度单季；
  资本/不良率等时点指标按9月30日核对。用于基础盈利的最近三年年度历史继续单独使用。
- 期间 matched 也可能缺部分核心数值，ready_for_scoring 始终为 false。官方来源、集团/
  法人及最新期完整性仍按行业规则核对，不能仅凭 matched 完成 financial 取证结案。

## 接口调研结论（2026-10-28）

| 来源 | 接口方式及覆盖 | 条件与本次验证 |
|---|---|---|
| 东方财富 F10 | 网站JSON接口 `RPT_F10_FINANCE_MAINFINADATA`；覆盖上表候选 | 无token的公开请求实测成功；内部接口没有稳定性承诺。已实现此脚本 |
| [理杏仁保险财报API](https://www.lixinger.com/api/open-api/html-doc/cn/company/fs/insurance) | 文档列ROE/ROA、新业务价值、核心/综合偿付能力等，可指定指标和期间 | 需token及相应权限；本次只确认文档，未用账户调取。法人覆盖/指标权限须另验 |
| [数立方银行专用指标](https://datacube.foundersc.com/document/2?doc_id=10383) | `bank_id`，含报告期、公告日、资本充足率、不良率等 | 需token与接口权限；文档存在不代表已获权限，未做真实账户请求 |
| [数立方保险专用指标](https://datacube.foundersc.com/document/2?doc_id=10392) | `insu_id`，含寿险/产险偿付能力、投资收益率、综合成本率、新业务价值及集团资本等 | 需token与接口权限；比通用接口更专门，但仍须确认逐法人、核心比率与风险评级覆盖 |
| [Tushare财务指标](https://tushare.pro/document/2?doc_id=79) | `fina_indicator`，ROE、加权ROE、ROA等一般指标 | 需token/积分权限；通用字段不能当作已覆盖银行/保险全套专用指标 |
| [金融监管总局统计](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1233335&generaltype=0&itemId=915) | 行业、机构类别的监管指标统计及附件 | 汇总数只作行业背景，不能替代某一家上市银行或保险法人的指标 |

本次只实现已真实跑通、无密钥的入口；不添加未经账户验证的收费接口适配器，不读取或
收集用户密钥。官方披露暂未确认有跨全部银行/险企、无需授权的完整统一JSON接口，
不能把“本次未确认”写成“绝不存在”。保留官方网页补齐路径。
