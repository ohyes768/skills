# 有限 PDF 补证

仅在接口候选和公告可读正文仍缺影响定分的表格、完整表头或脚注时读本页。
正文证据已足够就结束，不要求再读 PDF 来“提高可信度”。评级输入仍为 stock.json。

## 触发和范围

先写清缺哪个事实、影响哪个维度及判别规则，再选择同公司、同期间的官方原件。
常见缺口是银行 LCR/NSFR、完整适用资本要求与集团/母行口径；保险逐法人偿付能力、
风险综合评级、NBV 重述/精算假设、准备金及资产负债匹配说明。
普通企业 E 仍只用输入，不能借 PDF 补数绕过输入合同。

优先复用已有可信的页级缓存或原文。使用宿主已经可用的 PDF 阅读/提取能力；
需要时可使用已安装的 PDF skill，但它只提供读取能力，本 skill 的评分、预算和输出合同仍适用。
没有现成能力就记录缺口，不安装依赖、不恢复旧解析脚本、不临时编写爬虫或解析器。

## 有界读取与复用

- 用目录、已知表名或现成检索定位页码，再读相关页及必要的相邻表头、脚注。
  每份最多读 8 个不同页面，本轮最多 2 份、合计 16 页；目录页也计入。
  检索只返回命中页码和紧凑片段，不把整份年报输出到上下文。
- 页数上限是分析者执行约束，不是脚本或宿主自动拦截。沿用已有维度轮次和渠道故障状态，
  PDF 不另开取证预算；额度耗尽时不通过换工具、换格式或重启绕过。
- 宿主支持本地文件/页级缓存时，同一原件只下载、解析一次，后续读已有文件和摘录。
  缓存记录原始 URL、文件哈希、获取时间及页码；同 URL 内容变化视为新版，不能复用旧页码。
  宿主不暴露缓存时保存带出处的紧凑页摘录，后续直接复用，不声称已实现文件缓存。
- 提取结果缺列、顺序错乱或脚注截断时，用现成页图能力核对同一页；不能仅凭相邻数字填表。
  无可用页图、扫描件无法可靠读取或需另装 OCR 时停止这条路径，保留已确认事实并列缺口。

## 核对和交付

逐值确认发行主体、期间、集团/法人范围、单位、表头/行列及重述口径。
官方原件与转载平台的来源身份分开记录；转载不自动成为第一方认证或独立第二来源。
只保存实际读到的事实，PDF 链接、命中摘要和未读页不能作为已确认数值。

在 research.json 登记成功事实及来源定位；银行/保险同时将确认值写入独立证据包，
不修改 stock.json。缺少适用资本附加要求不能假定为零，缺保险法人指标不能拿集团代替。
到预算上限仍缺必需证据就按 null 收口，不把获取失败判成经营差。

report_md 继续使用 [S1] 及文末来源表，链接实际读过的 PDF，标注披露日期、事实期间、
文件页码、表名/行列和支持内容。无需新增最终 JSON 字段，也不附整份摘录。
