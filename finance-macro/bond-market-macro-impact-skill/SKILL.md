# 国内利率债：未来四周

默认从分析日起展望 28 天。每周可重新运行，但不自行创建调度。不上传信号 API、不触发上游数据更新；分析完成的报告按流程第 7 步推送到 RSS。只依赖公开快照 API，本目录脚本自包含，无需安装 A 股 skill。

## 流程

1. 阅读 [债市分析框架](references/analysis-framework.md) 与 [API 契约](references/api-contract.md)。
2. 从 skill 目录执行 `python scripts/fetch_snapshot.py`。可用 `--date YYYY-MM-DD`、`--output-dir PATH`，或 `--input PATH` 离线重放以前的 raw_snapshots.json。新输出目录不得已存在。
3. 阅读输出的 evidence.json 和 raw_snapshots.json：先看缺失、实际日期、观察点数量，再解释变化。逐指标取最近三个有效月份；当月未公布时用上期，不能把旧值冒充当月。日频比较采用分析日前 7/14/21/28 天快照，五个采样点不等于完整日线。
4. 按框架分别分析增长、通胀、政策资金、信用需求和外部约束。先写事实与反证，再给整体、短端、长端、曲线四项结论；不把 A 股结论取反，不沿用旧综合模型固定权重。
5. 阅读 `term_structure`：仅同日期、相同百分点口径的 10 年收益率与 10Y-2Y 利差可以反推 2 年收益率，结果标记“推导值”。DR007 是资金利率，不是短端国债收益率。没有可比期限数据时，曲线方向写无法判断。
6. 有此前报告时比较最近一份，无则标记首次分析。在本次输出目录保存 report.md，引用原始与整理证据，不覆盖历史报告。
7. 推送是必经步骤，不可省略：报告保存后运行 `python scripts/push_rss.py <report.md 路径> --title "<标题>" --insecure`。标题格式 `YYYY-MM-DD 利率债展望｜偏支持债券价格/中性分化/偏压制债券价格｜曲线趋陡/趋平/无明显方向`，日期与正文分析时点一致，第二段方向词必须出现在报告正文。质量告警在返回的 `quality_warnings` 中显示但默认继续推送；仅当用户明确要求硬门禁时加 `--strict`。标题与已发布条目完全相同（同日重跑且结论未变）时脚本返回 `duplicate: true`，属预期行为，不要重推；结论变化会体现在标题中，不受影响。推送失败时报告仍保留在输出目录，修复后重试即可。RSS 推送成功后脚本会自动追加推送一份到 macro 报告看板，结果看返回 JSON 的 `report_push` 字段：`ok`/`duplicate`/`failed: 原因`/`skipped_no_token`（token 读 `finance-macro/.env` 的 `MACRO_SIGNAL_UPLOAD_TOKEN`，缺失只告警跳过，RSS 仍算成功）；`failed` 时重跑整个脚本即可，RSS 侧 duplicate 检测与 macro 侧幂等会挡住重复。

## 数据判断

- 同比增速的跨月变化用百分点；PMI 用指数点。收益率差 0.01 个百分点 = 1 bp，不能把 0.1 个百分点写成 0.1 bp。累计同比与单月同比不能混用。
- 对每条证据同时说明当前水平、变化方向、基期和日期。不同月份及跨月缺档不能伪称环比；日频相同日期的回退只算一个观察点。
- 回退只是观测日期早于分析日，不自动判失效或降低整体把握；结合交易日、市场时差、正常发布节奏判断。周日日期提示核对，不宣称已确定数据错误。
- API quality=ok 不证明新鲜或来源正确。当前月尚未发布是正常滞后；发布时间已过但数据未变时提示核查，不擅自改数据。未知口径、冲突、未来记录和来源异常限制对应结论。
- 月频上游评分方向不一，不相加，不将“经济偏冷”自动换算为强烈债牛。LPR 不等于政策操作利率，单个 MLF 净投放值不等于全市场净投放。
- 交易活跃度、两融及 VIX 仅作风险偏好辅助；成交额不是净流入，股债也可能同涨同跌。北向是成交额，南向为港股资金活动。
- 本 API 无国债发行供给、期限溢价、债券仓位、信用利差、超长端行情或具体券久期。明确这些盲区，不能编造供给冲击、30 年行情、机构拥挤或杠杆策略。
- 历史月度记录可能修订，指定过去日期不构成无前视偏差回测。缺少实际行情与持仓参数，不测算具体券总回报。

## 输出格式

开头注明分析时点、四周区间、月度各指标所属期和最新日频日期。全篇使用以下明确方向：

1. **核心判断**：整体偏支持债券价格／中性分化／偏压制债券价格；短端、长端分别判断收益率下行压力／中性／上行压力；曲线趋陡／趋平／无明显方向或证据不足。注明把握高／中／低及原因、首次或较上期变化。
2. **主要驱动与反证**：数据值、比较基期、变动单位，沿“事实 → 资金／增长／通胀预期传导 → 期限差异 → 成立条件”解释。挑最重要因素，不凑固定数量。
3. **期限比较**：说明短端与长端是否同向；历史实际变化与未来条件性压力分开表述。不把较大利率下行空间等同于已实现回报。
4. **未来四周情景**：基准、转强、转弱及可观察触发条件；不编造概率、收益率目标或政策决定。分析自设阈值标注为假设。
5. **观察清单**：API 的 next_release_at 与持续观察项；估计发布时间须注明，缺失则待确认，展望期外事件单列。
6. **数据限制和复盘**：说明影响哪些结论的缺口；比较上次主要驱动如何变化。信用债不纳入结论。

若增长通胀背景和资金／收益率证据均不足，不给整体方向；只有局部缺失时限制相应部分。收益率下降一般支持固定现金流债券价格，但总回报还受票息、持有期、融资成本等影响，不能把二者等同。
