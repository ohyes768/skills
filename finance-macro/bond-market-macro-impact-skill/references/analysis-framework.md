# 国内利率债传导框架

范围为未来四周国内利率债，以国债 10Y 与可推导的 2Y 为期限观察锚点；不把它外推为全部政策性金融债或超长债的确定表现。

## 四条主线

| 主线 | 常见债市传导 | 必须核对的反证 |
|---|---|---|
| 增长与信用需求 | 需求走弱可能降低增长和利率预期，支撑债价；修复可能增加收益率上行压力 | 信用总量可能由政府融资而非私人需求驱动；供给结构缺失时不能分辨 |
| 通胀 | 通胀预期回落可能降低名义收益率压力 | CPI/PPI 已实现值不等于预期；成本型 PPI 上升不能直接认定需求过热 |
| 政策与资金 | 资金稳定或缓和有助持有与融资，通常更直接影响短端 | LPR 与资金价格不是同一层次；弱经济不保证降息，长端可能提前交易预期 |
| 外部与风险偏好 | 汇率、外部利差可能约束国内宽松；避险需求可能支持利率债 | 外部冲击也可能造成流动性紧张和股债同跌；人民币变化不等于跨境净流量 |

各主线分开列支持、压制、未知，再识别当前主要矛盾。禁止按指标票数决定结论，组成利率和衍生利差不重复计票。五个日频采样点允许描述观察到的变化，不能据此声称趋势连续或交易拥挤。

## 短端、长端与曲线

短端以政策和资金预期为主，2Y 仅作为可用期限代理；DR001/007 只能说明银行间资金条件。长端还承受中期增长、通胀、供给与期限溢价影响；后两项没有数据，不能假设为零。

定义曲线斜率 S = Y10 - Y2，单位百分点。仅同日期、同单位可推导 Y2 = Y10 - S。比较须两端同日配对且跨期日期一致，脚本提供共同日期序列。S 上升为趋陡，下降为趋平，不能单靠 S 变化判断牛熊。

| 已观测变动组合 | 可用表述 |
|---|---|
| 两端收益率下降，短端下降更多 | 牛陡 |
| 两端收益率下降，长端下降更多 | 牛平 |
| 两端收益率上升，长端上升更多 | 熊陡 |
| 两端收益率上升，短端上升更多 | 熊平 |
| 两端方向相反或一端不变 | 直接描述各端及斜率变化，不强套牛熊标签 |

上表用于解释过去变化；未来走势要另列条件，不从历史标签自动延伸。久期更长通常对收益率变化更敏感，但缺具体券久期、凸性和融资成本时不计算收益、不建议杠杆倍数。

## 情景与把握

资金缓和而经济改善：短端可能受支持，长端受增长修复约束，不能概括为全曲线债牛。

经济走弱而资金收紧：增长支撑与融资约束相抵，优先区分期限，不直接判利好；现金需求可能压制债券价格。

通胀下降但收益率已下降：缺乏预期和估值信息，不声称未来仍有确定空间，也不声称利好已充分定价。

回退到上个交易日且数据完整：正常可用，标明日期即可；长期不更新或跨日期错配才降低相关判断把握。周日标记仅提示来源核对。

高把握须关键证据充分、口径和日期可信、独立传导一致；中为证据有分歧或局部缺失；低为关键主线无法验证。此分级不是债券价格上涨概率。

复盘对照资金价格、长短端压力、增长通胀验证及外部约束是否改变。首次报告不得伪造上周判断。优先给方向与成立条件，不设固定权重总分。
