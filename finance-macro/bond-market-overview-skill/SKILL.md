# 债市宏观环境综合分析

## 核心原则

不要把缺失数据当作中性数据。只要核心宏观数据缺失、过期、读取失败或没有明确评分，就输出“本周债市判断不可用”，并说明原因。

债市判断必须分三层：

1. 数据是否可靠
2. 债市核心底色
3. 短期市场情绪

推荐表达：

```text
债市底色：中性
短期情绪：偏热
综合判断：多空交织，票息和中性久期更合适。
```

## 工作流程


这会为货币、信用、经济、通胀、外部压力生成 `macro_signal.json`（写入统一输出目录 `finance-macro/output/<skill 目录名>/`）。

风险偏好来自：

```text

```

如果未来风险偏好也生成 `macro_signal.json`，债市脚本会优先读取它。

### 2. 运行债市总分析


结果写入：

运行输出必须先展示 6 个维度详细数据，再展示总结：

```text
短期情绪：xx
综合判断：...
```

## 债市映射规则

债市和 A 股不同，很多维度要反向理解。

| 维度 | 对债市含义 |
|---|---|
| 货币政策 | 越宽松越利好债市 |
| 信用扩张 | 信用越强，债市越容易被分流，偏不利 |
| 经济运行 | 经济越强，利率上行压力越大，偏不利 |
| 通胀环境 | 通胀越高，名义利率压力越大，偏不利 |
| 外部压力 | 汇率和外部压力越稳定，越利于国内宽松 |
| 市场情绪 | 风险偏好越热，债市短期越容易承压 |

核心债市指数只包含：

| 维度 | 权重 |
|---|---:|
| 货币政策 | 25% |
| 经济运行 | 22% |
| 通胀环境 | 22% |
| 信用扩张 | 16% |
| 外部压力 | 15% |

风险偏好不进入核心指数，只作为短期情绪说明。

## 结论分档

| 债市核心指数 | 结论 |
|---:|---|
| 80 以上 | 明显利好 |
| 65-79 | 偏利好 |
| 45-64 | 中性 |
| 30-44 | 偏不利 |
| 30 以下 | 明显不利 |

## 输出要求

报告必须包含：

1. 数据质量：哪些维度可用，哪些缺失、过期或报错
2. 六个 skill 的详细数据：货币、信用、经济、通胀、外部压力、市场情绪
3. 债市底色：核心债市指数和定性结论
4. 短期情绪：风险偏好温度
5. 综合判断：说明“中期债市环境”和“短期情绪压力”是否一致
6. 策略含义：久期、杠杆、票息优先级

如果数据不可用，报告不得出现“利好/利空”最终判断，只能说明“本周债市判断不可用”及原因。
