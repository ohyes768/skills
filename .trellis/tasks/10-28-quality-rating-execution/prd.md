# 基本面评级执行预算与交付闭环

## 目标
按用户确认的五项建议约束开工、逐轮取证、结案、改分和交付，避免重演 f88f60 会话的超时与失配。

## 验收
- 开工保存唯一输入及账本，研究前声明缺口；持久化全局研究预算，不因重复 init、换维度或重开恢复。
- 已结案只能有具体冲突才重开；成稿前全部结案，改分后旧计算快照不得通过最终校验。
- 预留交付调用；finalize 成功产出唯一十字段 JSON 文件，失败不输出可交付结果。
- 保留五维评分、金融证据合同及旧 CLI 兼容；清楚区分脚本约束与宿主绕过能力。
- 回归测试通过，按用户最后指示提交并推送 Git；NAS 安装副本暂不同步。

## 本轮追加要求
- 禁止评级运行下载、解析或读取 PDF（含缓存及其他 skill）；搜索并读取网页正文，关键缺口按 null 收口。
- 每维初查加四轮网页补查；保留全局 24 次取证及 8 次交付预留，不以增加轮次要求耗尽预算。
