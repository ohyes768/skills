# 优化方案草案

以下为待实施方案，不代表能力已经交付。

## Skill 内改进

- R1：从 archive、映射、指标三个层次输出 coverage，分别表示请求/报表/字段/映射/计算/模型输入的可用性，自动提供正确的限制描述。
- R2/R4：标准分析包补充毛利率、费用率、余额变化与利润变动桥；统一 Decimal、期间和来源绑定，必要事实纳入独立复算。缺项保留缺失，禁止 null 转零。
- R3：build_report_spec 待办带章节、段落位置、句数余量、可用证据及缺失限制。生成的数据绑定由程序负责，模型只编辑指定定性段落。
- R4：统一 compute/pack_context envelope 并提供可运行续页示例；先检查消费者再确定共同 packet 结构与过渡适配。错误游标不能静默视为结束。压缩重复元数据仍须可按 ID 追溯完整来源。
- R2：对比较基期、覆盖状态、利润贡献方向建立确定性支持条件。自然语言因果保留语义复核及限定，不以关键词匹配声称所有判断已验证。

## 外部依赖

- stock-info-dingding：提示词与合同同步，仅需产物时不请求 include-report，保持代码/期间/来源绑定与已验证结果验收。
- Hermes：先调查工具授权及循环终止能力，再落实正常分析不读源码、只写指定段落、终态立即结束。不能只增加提示词就称已隔离，也不能封掉正常 CLI 所需能力。
- 外部改动独立验收；未实施内容明确列作依赖，不在本次建档中部署或修改。

## 兼容及回滚

维持 F10-only、留档 hash、来源与期间合同、指标不可任意编辑、独立复算及持久修复预算。合同变化同步版本和消费测试，每阶段可独立回退，不覆盖历史正式报告或改写留档/校验结果。
