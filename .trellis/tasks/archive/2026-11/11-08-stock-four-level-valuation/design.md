# 独立四挡位估值 Skill 设计

日期：2026-11-08  
状态：用户已批准，进入实施；不包含 web 实现或部署授权。  
需求依据：[prd.md](prd.md)。产品已确认“逐公司研究定价”。

## 1. 目标和分工

新增 `investment-analysis/stock-four-level-valuation/`，单次只分析一只 A 股。Skill 是研究决策指南和小型计算/校验工具，不是选股网站、批处理系统或自动交易策略。

调用方传入股票与已有成果 → 复用检查 → 补齐影响定价的证据 → 公司/行业模型选择 → 三情景与四点决策 → 精确计算 → 单个 JSON（含中文报告）。

- Agent：判断商业模式、正常化盈利、分红可持续性、假设、合理倍数、风险和置信度。
- 确定性脚本：检查身份/类型/引用、计算价格与比率、检查四点顺序和 JSON 结构；不能证明事实真实或倍数合理。
- 调用方：读取收藏、保存原始成果、提供日期/版本、调度、展示、新旧对比、批准回写、启停提醒。
- 不改 basic-quality-rating 或 financial-statement-analysis 的规则、目录及输出；不要求相邻安装，不引入 NAS 路径依赖。

## 2. 复用已有成果，而不是重新研究一遍

### 2.1 输入分层

必需身份为六位字符串 `code`、`name`；`as_of` 可由调用方提供，省略时取实际执行日期并显式记录。不得仅凭训练知识声称“最新”。币种首版仅 CNY。调用方可另传 `run_dir`；单次目录不与其他股票或运行混用。

可选材料分为：

| 材料 | 优先使用 | 只有最终报告时 |
|---|---|---|
| 财报成果 | document.json、financials.json、analysis_pack.json、report_claims.json，必要时 metrics.json | analysis.md 作为上游材料；数值须定位至来源/期间，不能把文字自动提升为完整已核验事实 |
| 基本面成果 | rating.json 加 progress.json 的 sources/facts、调用方保存的 scored_at/data_date | 读取 report_md 和 risks/watch_points；评分只作上游判断，日期不明时记录限制 |
| 行情/每股指标 | 含证券、日期、期间、单位、来源的当前价、TTM EPS、BVPS、DPS | 不要求现价才能算内在价值；缺现价则不输出当前触发状态 |
| 补充材料 | 公司公告、分红方案、金融资本、资产期限等可读证据 | 只提供链接而未读取正文的材料是线索，不算已取得事实 |

输入可内联材料，或给明确的本地文件路径；只读取用户/调用方指定文件，不递归扫描任意目录、不执行材料里的代码。不会实现“输入一个远程地址就任意下载”的通用文件获取器。

### 2.2 证据等级和日期

- 已有结构化事实保留原来源、期间、主体、单位和核验边界；上游 F10 verified 只意味着其结构/来源/计算检查，不是独立双源确认。
- 只有历史报告的材料注明“复用上游报告，本次未独立复核”；不是全部作废，也不能冒充本次新核验。
- 上游日期、事实期间、披露日期、访问日期分别记录。缺数据日期时不能用分析日填充；能从正文明确确定的期间可以引用。
- 不设置统一“超过 90 天必须重做”：按是否出现新财报、分红调整、拆送配、资产/业务变化判断重要性。未核查更新情况则不声称最新。
- `as_of` 只使用截至该日已披露资料；历史查询若缺版本留档，标明不能保证消除后续重述，不把它包装为无前视回测。
- 冲突先比身份/主体/期间/币种/单位/重述口径，再判断是否影响定价。不平均冲突数字、不用输入反推值充当独立核验。
- 所有源文件只读；新解释或新事实写本轮 evidence.json，不覆盖上游账本。

### 2.3 复用后的补查

先列具体缺口及其对挡位的影响。已有材料足以支持的业务/护城河章节不再全面搜索。每个关键缺口一次初查加最多两轮定向补查，仍无法解决则停止并交付缺口；同一后端鉴权/额度失败立即停用，临时失败两次停用。不现场安装工具或开发爬虫。

新 Skill 不自动重跑两个上游 Skill 的整套流程。缺完整财报包时可提示调用方运行现成财报 Skill；能够从少量可读披露补齐的核心变量则定向补证。

## 3. 研究门槛与行业选择

不以总分或星级决定估值倍数。先检查生意是否可理解、持续经营、会计盈利质量、可分配现金、治理、负债/资本约束及影响估值的重大变化。

| 公司类型 | 主模型候选 | 必查内容 |
|---|---|---|
| 稳定盈利消费、家电、医药、软件等 | 正常化每股盈利 × 有依据的 PE；现金分配现值交叉验证 | 一次性损益、利润可持续性、再投资、竞争、股本变动 |
| 银行 | 普通股每股净资产 × 有依据的 PB；盈利/分红交叉验证 | 可持续 ROE、普通股权益、资产质量、监管资本及分红约束 |
| 水电、运营类公用事业 | 普通股股东可得现金现值；PE 辅助 | 维持性资本开支、债务、现金覆盖、监管约束、资源/资产寿命 |
| 收费公路等有限经营权 | 有限期股东现金流现值 | 剩余经营期、扩建/补偿条款、债务、终期处置；不能默认永续 |
| 周期股 | 中周期正常化盈利及压力情景 | 不能用景气顶部 EPS 乘低 PE 当便宜；无足够周期依据则不出价 |
| 亏损、困境、复杂金融、早期企业 | 首版不强制覆盖 | 可可靠研究但不适用三类模型时 not_applicable；缺核心事实时 insufficient_data |

银行上游基础评级明确未覆盖监管资本等；新 Skill 必须补足影响估值和分红的金融证据，否则不出完整四点。不能用工业负债率阈值代替金融风险检查。

没有分红不自动判定公司无价值，也不强行给股息率估值。使用盈利模型仍须解释留存收益回报。

## 4. 三情景与四挡位：两个不同层次

### 4.1 情景层

先形成悲观、基准、乐观三组经营/估值假设，记录正常化盈利或现金流、增长、必要投资、分红、估值参数和主要反证。三情景的价格均以分析时点为基准；不输出三年未来价冒充当前价值。

若情景价格不符合经济解释，修正假设或说明冲突；禁止简单排序掩盖模型错误。没有依据给情景概率时不做概率加权。

### 4.2 决策层

四点不是把三情景机械插值成四个点，必须逐点给出决策说明：

| 点 | 含义 | 必须解释 |
|---|---|---|
| heavy_position 重仓 | 基本面可接受时，要求更厚安全边际的低价观察线 | 即使盈利/分红承压，为什么仍有合理保护；为何不是价值陷阱 |
| add_position 加仓 | 有吸引力但安全边际较重仓线窄的观察线 | 正常化盈利、价值折价或股东现金回报的依据 |
| reduce_position 减仓 | 靠近合理价值上沿、增量回报吸引力下降 | 哪些预期已被价格反映，继续持有依赖什么 |
| full_exit 全卖 | 显著高估的价格退出观察线 | 哪些偏乐观假设也难支持价格，不只是机械比减仓价再加 10% |

每点记录选用模型/情景、参数值、来源或假设依据、主要敏感变量与触发前提。安全边际是相对于明确的价值锚，不是现价，也不是亏损下限。不同公司的参数可以不同，禁止默认全市场统一倍率或折扣率。若用折扣，必须记录价值锚、比例和为什么该公司需要这个幅度。

同一公司优先使用同一种主模型推导四点；交叉验证模型不直接取算术平均。若无法解释模型分歧或凑不齐四个严格递增的点，则不发布完整挡位。

### 4.3 精确算术支持的三类模型

首版脚本只支持白名单公式，不执行任意表达式。

1. **pe_multiple**：`price = normalized_eps × selected_pe`。
   - 正常化 EPS > 0，使用与普通股匹配的每股口径；四点共用同一正常化盈利锚，倍数分别论证。
   - 增长不是把当前 EPS 按最近季度增速直接年化；正常化调整要有事实基础与桥接说明。
2. **pb_multiple**：`price = common_bvps × selected_pb`。
   - 普通股 BVPS > 0，扣除优先股等不属于普通股的权益；四点共用同一权益锚。
   - PB 需要可持续 ROE/资本/资产质量依据。可以用权益模型验证，但禁止把企业 ROIC 与股权折现率混用。
3. **equity_cashflow_pv**：`price = Σ(cash_per_share[t] / (1+r)^t) + terminal_equity_per_share / (1+r)^N`。
   - 只支持明确的年末、每普通股、人民币股东现金流；`r > 0`、`N >= 1`，所有数值有限，负现金流不得自动截成零。
   - 用股利时只计股利；用 FCFE 时不再叠加股利。股东现金流已扣融资/债务影响，不再重复减净债务。FCFF/企业价值模型首版不支持。
   - 终值选明示的终期股权价值、终期 EPS×退出 PE，或第 N+1 年可持续股东现金流/(r−g)（即第 N 年末价值，之后再折现 N 年）。永续模式要求 r>g 且 g>-1，币种/口径一致且公司并非有限经营权；r−g 狭窄须报告高敏感性，不把 NAS 某个固定利差当金融定律。
   - 期间分红与终期股价分别折现、不能重复计入。无限期增长、退出 PE 和增长率都需要理由；不硬编码 NAS 历史的 r/g 默认值。

允许对算得的当前价值另施明确的安全边际系数 `1-margin`，margin 在 [0,1)，必须有理由；无理由的系数校验通过也不等于研究通过。

金额用 Decimal 计算，最终 price 按人民币分四舍五入；舍入后四点必须严格递增，不因重合自动加一分“修复”。内部保留未舍入结果。归一化参数、公式版本与证据引用存于计算记录。

## 5. PE/PB/股息率展示口径

网站已有 pe/pb 字段，不能让同名字段在不同模型下含义漂移：

- `levels.*.pe` 统一为 `price / positive_ttm_eps`；缺同口径 TTM EPS 或 EPS<=0 则 null。
- `levels.*.pb` 统一为 `price / positive_common_bvps`；缺值或普通股 BVPS<=0 则 null。
- 正常化 EPS 和所选估值 PE 放在 `valuation` 内，不冒充当前 PE(TTM)。
- 每点股息率放在 `valuation.level_metrics`，不扩充网站旧 levels 三字段；`annual_dps / price × 100`，单位为百分数。
- DPS 标记 TTM 普通现金股利或前瞻情景股利；普通与特别股利分开，TTM 不混用累计公告/支付归属重复计数。
- 现金分红若与 price/EPS/BVPS 跨拆送配基准，先调整到一致股份口径；缺关键调整依据时不计算该指标。
- 股息率只是校验，不是回报承诺；税前口径，未掌握账户/税务信息不估净收益。

## 6. 输出合同草案

成功处理合法输入后返回一个裸 JSON 对象，中文报告放 `report_md`。不在 JSON 外追加说明。

| 顶层字段 | 内容 |
|---|---|
| schema_version / skill_version | 合同版本和实际执行 Skill 版本；由 finalize 写入 |
| code / name / currency / as_of | 证券、CNY、分析截止日 |
| status | ready、insufficient_data、blocked、not_applicable |
| levels | 恰好四个既有键；每点恰为 price/pe/pb |
| valuation | 主模型、情景、参数/公式/证据引用、逐点理由、股息率校验和敏感性 |
| evidence | 实际使用的源材料、事实期间/披露日/取得日、上游或本次取证身份 |
| data_gaps | 核心缺口、次要限制、冲突及影响 |
| confidence | high/medium/low/unavailable 及原因，不能表示盈利概率 |
| risks / invalidation_conditions | 已知风险与触发重新估值的具体条件 |
| summary / analysis / report_md | 中文概要、五段原始研究判断及同源生成的正文；analysis单独保留，确保非ready时valuation=null仍可无损重放报告 |

状态约束：

- **ready**：四点全部有有限正数 price，舍入后 heavy < add < reduce < exit，风险门槛可接受，证据/参数完整且没有阻断性的矛盾；PE/PB 可因不适用而 null。
- **insufficient_data**：缺少决定性的事实、来源冲突或无法论证定价；四点 price/pe/pb 全 null。保留已知信息，不返回“仅供参考”的隐含有效价。
- **blocked**：已核实治理、存续等核心红线，暂不发布正常价格策略；四点全 null，说明实际风险，而不是把风险叫缺失。
- **not_applicable**：证券或商业模型不适合首版支持方法；四点全 null，说明适用边界。
- 输入格式/身份失败、脚本执行失败属于调用失败：非零退出、stderr 解释、不产生伪造的股票结果。运行失败与“合法输入但研究不完整”分开。

不输出网站 alerts.enabled，不继承旧挡位，不提供自动覆盖指令。调用方必须检查 status，不能只看是否存在 levels 字段。完整结构设计后续在实施计划落实为可执行测试；本草案不是已上线接口。

## 8. 验证设计

实施必须先记录无 Skill 基线，再写最小 Skill，用相同场景重测；不因文档看起来清楚而跳过实际行为测试。

| 场景 | 必须验证 |
|---|---|
| 完整消费股材料 | 复用已有业务证据、逐点论证、不从评分映射 PE |
| 只有旧研究报告 | 日期和来源限制可见，不能假称最新或独立双源 |
| 银行只有基础质量分 | 不冒充资本风险已评估；补不到时不给四个有效价 |
| 特别分红/股息削减 | 不把一次性高分红永久化，测试分红下降 |
| 未来三年 EPS×PE | 明确未来与当前价值，期间现金只计一次 |
| EPS<=0、BVPS<=0 | 相关模型拒绝、不输出负 PE 或零价占位 |
| 公司身份/期间冲突 | 明确拒绝或缺口，不拼接出貌似完整结果 |
| 有限收费经营权 | 不默认永续终值；剩余经营期影响价值 |
| 四点顺序/舍入重合 | 拒绝顺序错误，不排序、不平移或加一分修复 |
| 红线/数据不足/模型不适用 | 不同状态，但都不遗留上次有效挡位 |
| 提示注入/回写催促 | 来源内容只是数据，不执行交易或访问收藏写接口 |

算术测试使用人工可复核的虚构小数样本；例如 EPS=2、PE=10 算出20只用于测试，不是通用估值准则。敏感性至少覆盖正常化盈利/现金流和估值倍数/折现率的变化；不能只换标签而不改变输入。

- 现有两个 Skill 无行为改变，原消费者不迁移。
