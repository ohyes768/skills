# 收藏股票独立四挡位估值 Skill

## Goal

提供可独立调用的单只 A 股估值 Skill，将可追溯的财报、基本面研究和必要的补充证据转为重仓、加仓、减仓、全卖四个价格观察点，附估值依据、数据口径和风险。价格观察点不等同于个性化仓位建议或交易指令。

## Requirements

### R1 — 单股输入和独立边界

接收六位 A 股代码、公司身份、分析截止日，以及可选的既有财报/基本面研究成果。保留前导零。允许聊天单独调用或外部任务调用，不要求连接网站。身份错误与关键材料不足必须区别处理。

### R2 — 有依据的复用与定向补证

优先复用公司、主体、期间、币种、口径匹配且适用于本次分析的已完成研究；分别保留事实、上游判断和本次假设。不能把历史评分换算为 PE，不能把同源研究当作独立双源核验。仅在影响定价或核心风险判断时补查，缺日期不补造日期，不把取得时间当披露日。

### R3 — 四挡位与估值逻辑

四点必须同币种、同估值时点，具有递增价格次序，每点能解释估值基础及触发含义。已确认采用逐公司研究定价：按行业选适用模型，结合分红可持续性与情景分析；不得按当前股价固定涨跌幅生成，也不默认统一四档回报率。未来目标价必须先处理时间价值和期间分配，不能直接作为今天的观察线。

### R4 — 风险及缺失传播

区分资料不足、模型不适用与已核实基本面风险；不以低价抵消治理、存续或分红不可持续风险。不使用零、负 PE、默认中性假设凑出有效挡位。无足够依据时允许不出价，保留原因和补证清单。全卖价格线与基本面失效红线必须分开，跌破重仓价不自动表示可买。

### R5 — 可复算的结构化交付

输出单个结构化结果及其中的中文分析报告，提供四挡位、PE/PB（仅适用时）、估值依据、数据截止日、置信度、来源、风险和失效条件。所有价格与比率须可从列明输入和公式复算。估值口径与行情显示口径不一致时明确区分，不能伪装成同一 PE。

### R6 — 兼容和克制

新增独立 Skill，不修改现有两个 Skill 的输出合同和研究规则，不要求安装整个 AI Berkshire。借鉴其研究和算术校验方法，不机械照搬固定阈值、人物口吻、全部长报告章节或历史股价/每股数据混用方法。

## Acceptance Criteria

- [ ] AC1 → R1：单只有效 A 股可独立分析，代码前导零保留；身份矛盾返回明确输入错误。
- [ ] AC2 → R2：完整上游证据被复用，不从零重复整份研究；只有旧正文或缺日期时明确限制，不能声称独立核验。
- [ ] AC3 → R3/R5：消费企业、银行、公用事业/经营权资产场景能选择适用方法；成功结果恰有四个有依据的价格，满足严格递增且计算可复现。
- [ ] AC4 → R3：测试证明不把三年目标价直接写为当前四挡位，期间分红既不遗漏也不重复计入。
- [ ] AC5 → R4：缺必要估值基础、重大来源冲突、负盈利不适用 PE、金融资本证据缺失和基本面红线场景，不发布看似完整的有效价格信号。
- [ ] AC6 → R5：区分正常化 EPS、TTM EPS、年度 EPS；分红按每股现金额、期间和普通/特别性质记录，不能从历史股息率直接倒推稳定分红。
- [ ] AC7 → R5：JSON 与中文报告中的四点、状态、期间和风险一致；置信度不表示赚钱概率。
- [ ] AC8 → R6：未更改既有 Skill 的输入输出，未读写收藏、未回写网站、未执行交易。
- [ ] AC9 → R2/R4/R5：在编写 Skill 前记录无 Skill 基线测试；编写后同场景对比及边界测试通过，自动校验与金融判断的能力边界有明确说明。
