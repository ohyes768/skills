# A 股财报 PDF 分析 Skill

状态：planning。2026-10-16 创建；本轮交付规划，开发与效果验证尚未执行。

## 目标与用户价值

输入一个财报 PDF 链接，获得带原文页码证据的中文 Markdown 分析，帮助用户理解经营变化、盈利质量、现金与负债、财务风险。用户无需先下载 PDF 或手工指定章节。

## 已确认背景

- 用户明确输入为 PDF 链接，输出为 Markdown，A 股为主。
- 分析主线参考 HKUDS/Vibe-Trading 的 financial-statement skill。
- 已讨论并采用本地建立全文索引、模型按需读取重点证据的方案；用户关心 token 消耗。
- 用户要求创建 Trellis 任务并规划。本次授权不包括实施业务代码、发布 skill 或 Git 提交。
- 既有详细设计：`docs/superpowers/specs/2026-10-16-financial-statement-analysis-design.md`。

## 需求

| ID | 需求 |
|---|---|
| R01 | 仅以 `pdf_url` 为必填项；自动识别公司、期间、币种、报告类型及全文/摘要。 |
| R02 | 下载真实、可打开的 PDF；支持重定向、超时、有限重试、内容缓存和原文追溯。 |
| R03 | 全文建立页码索引，优先读取财务摘要、管理层讨论、合并三表及审计报告；对重要事项初筛并按问题回查附注。 |
| R04 | 保留表头、期间、单位、科目和跨页关系；原生、扫描及混合 PDF 按可用能力处理，识别失败必须可见。 |
| R05 | 财务数字结构化且有来源；合并/母公司、归母/集团、累计/单季、调整前/后不得混用，缺失不得当作零。 |
| R06 | 派生指标由脚本计算并保留输入来源；覆盖增长、盈利、现金流、资产负债、周转和杜邦分解，检查三表适用的勾稽关系。 |
| R07 | 模型基于证据分析，异常先回查解释；风险信号区分触发、已检查未发现、资料不足、行业不适用。 |
| R08 | 输出 `analysis.md`，包含核心结论、关键指标、经营与三表、盈利质量、杜邦、风险、未验证事项和来源。 |
| R09 | 控制送入模型的内容规模；记录上下文交付量与实际可获取的模型用量，准确区分实测和估算。 |
| R10 | 年报优先；半年报、季报、摘要根据披露范围降级。银行/保险/证券仅做适用的基础分析并提示专用框架缺失。 |
| R11 | 可在仓库内按既有 Python skill 方式运行；复用缓存、按阶段重跑，源码与运行产物分开。 |

## 验收标准

下列为开发后的验收目标，尚未执行：

- [ ] A01 / R01-R02：公开有效 PDF 能下载与识别；HTML、失效、超限、损坏或加密但无密码的输入产生明确诊断，不生成假报告。
- [ ] A02 / R03-R04：文字年报定位到正确的合并三表、管理层讨论和审计页；跨页表格、目录偏移和扫描表格有样本验证。
- [ ] A03 / R05：人工标注的关键字段在可识别样本中全部匹配，金额精度、期间、范围及来源页码正确；识别不了的字段有缺失原因。
- [ ] A04 / R06：平均余额、归属口径、汇率调节、资本支出、负基期和零分母案例通过；计算结果可复现。
- [ ] A05 / R07-R08：最终报告的每个关键数字和风险结论均能追溯原文或有来源的计算；机器校验通过后再做语义审阅。
- [ ] A06 / R09：不把全文作为脚本 stdout 或工具返回值；默认每个上下文包最多 12,000 个 Unicode 字符，长章节可分页，主动记录已读取内容。
- [ ] A07 / R09：对至少一份超过 100 页的文字版年报，按相同工具交付量口径比较全文读取和按需读取；以减少至少 50% 文本交付量为初始优化目标，同时保留 A03/A05。未达到时记录原因并继续优化，不能仅靠删除证据达标。
- [ ] A08 / R09：有宿主用量日志时记录实际 input/output/cached tokens；没有时置为空并标注不可获取，字符统计或 tokenizer 估算不得冒充计费总量。
- [ ] A09 / R10：季度累计、亏损、重述、摘要、缺少审计报告及金融企业样本均按披露条件降级，不产生无来源历史趋势。
- [ ] A10 / R11：离线回归、真实样本复核和完整 skill 行为验证通过后，更新仓库索引；安装与发布不属于本任务自动动作。

## 范围边界

第一版主要服务 A 股非金融企业。采用单份 PDF 内可用的比较期数据，不自动抓取额外历史年报、行情、预测或行业数据库；不包含估值、目标价、交易建议、综合财务评分或造假概率。OCR 可选，环境缺失时必须明确降级；不默认上传外部解析服务。
