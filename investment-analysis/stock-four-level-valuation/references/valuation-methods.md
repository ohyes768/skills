# 四挡位研究与估值方法

## 1. 门槛先于价格

先判断主营、盈利可持续性、现金分配、必要投资、治理、债务与存续。不拿便宜抵消已证实的严重治理/存续风险。不把材料少直接判公司差，也不能因为缺证据就用低PE“保守出价”。

银行专用门槛：普通股权益、资产质量、不良与拨备、监管资本/分红限制及主体范围。现有基本面基础评分未评估这些风险；证据未齐时insufficient_data，而不是因为4分就出四点。保险/复杂金融首版不强求覆盖。

## 2. 模型路由

| 生意 | 主模型 | 关键检查 |
|---|---|---|
| 稳定盈利消费/家电/医药/软件 | 正常化 EPS×合理 PE，现金回报交叉验证 | 一次性损益、竞争、再投资、留存收益回报、股本变化 |
| 银行 | 普通股 BVPS×合理 PB，盈利/股利验证 | 可持续ROE、普通股权益、资本与资产质量 |
| 水电/运营公用事业 | 股东现金流现值，PE辅助 | 维持性资本开支、债务、监管、资产寿命 |
| 收费公路/有限经营权 | 有限期股东现金流现值 | 剩余年限、扩建、补偿和终期回收，禁止默认永续 |
| 周期企业 | 有依据的中周期正常化盈利 | 不用顶部EPS配低PE，缺周期基础时不出价 |
| 亏损/早期/复杂资产 | 不强求本版模型 | 可换适用模型但不能编正EPS；都不适用则not_applicable |

没有股利并不等于零价值。特别股利不能外推，历史股息率不能代替普通DPS。数据平台的PE缺分母口径时不能直接当已验证TTM。

## 3. 情景不是挡位

先作悲观、基准、乐观的**当期价值**：每组说明经营假设、正常化盈利/现金分配、必要投资、增长及估值参数，记录反证。禁止只换情景标签不改经营假设，或用同业平均替代所有论证。

可以用历史同口径估值及同业研究校验当前倍数，但要解释结构变化/差异，不能认为过去贵就合理、均值回归必然发生。未来退出倍数尤其要与届时增速、资本回报和分红能力一致。没有可信概率就不算概率加权。

然后独立解释四点：

| 挡位 | 对应研究结论 |
|---|---|
| 重仓 | 在风险前提仍成立时，更厚安全边际的低价线；悲观经营下为何仍有保护 |
| 加仓 | 正常化价值有折价、回报吸引力较强；保护不如重仓线厚 |
| 减仓 | 接近合理价值上沿，增量回报下降；继续持有依赖哪些预期 |
| 全卖 | 明显偏贵，甚至合理乐观假设难支持；与基本面红线是两回事 |

**每点都必须解释每个重要倍数、折扣、现金流/增长、折现率的取值依据及主要敏感变量。** 同一公司四点优先同一主模型；PE共用正常化EPS，PB共用普通股BVPS。交叉模型只作检查，不直接平均。

不能从现价上下10%/20%、评分映射PE、单一现值任意乘0.6/0.8/1/1.2，或三情景插值凑四点。已经声明“观察线”“非投资建议”“未经校准”也不能绕过。研究只支持一个现值而不支持四点时，正式结果不足、四点全null；不在正文/附录偷偷给一套完整参考价。

安全边际比例不是固定公式，使用时解释相对哪一价值锚，以及公司不确定性为何需要此幅度。风险不等于股价波动，不能用折扣宣称最多亏多少。

## 4. 白名单数学及口径

所有敏感计算用随附工具，禁止任意eval。模型实际字段见 [输出合同](output-contract.md)。

- **PE**：正常化每股收益×选定PE，两个值>0。
- **PB**：普通股每股净资产×选定PB，两个值>0。不能用包括优先股的集团权益默认替代普通股权益。
- **股东现金流现值**：逐年年末 `CF[t]/(1+r)^t` 求和，再加第N年末股权终值折现N年。r>0，最多100年，允许负CF但不能自动截零，最终观察价必须正。
  - 采用股利时只计股利；采用FCFE时不重复加股利。FCFE已处理净借款等股权融资影响，不再减一次净债务。
  - 不把FCFF/WACC与股权终值、普通股分红混用；首版不计算企业价值模型。
  - 终值可取明确终期股权价值、终期EPS×退出PE，或**第N+1年**可持续股东CF/(r−g)。后者算出第N年末价值，必须再折现N年，要求r>g、g>−1；有限经营权禁止永续。
  - 终期股价必须明确是否除掉当年已计股利，避免重复。折现率与现金流同币种，现金/名义口径一致。r−g很窄必须在分析强调敏感性，不能照搬某固定利差假装金融定律。
- 可显式施 `1-margin`，0<=margin<1，但参数必须经研究说明；程序只验证数值范围。

当前价格按人民币分ROUND_HALF_UP；指标按最终舍入价计算、四位小数。舍入后必须重仓<加仓<减仓<全卖，不排序、不加一分钱修正。未舍入价格留在审计结果。

## 5. PE/PB、分红与股份基础

输出levels.pe固定为价格/正TTM EPS；levels.pb为价格/正普通股BVPS。缺失或分母非正则null。不把估值使用的正常化PE塞成TTM PE；选定倍数留在model。

股息率=普通年度DPS/价格×100，明确TTM普通分红或前瞻普通分红，税前。特别分红单独解释、不计入普通DPS字段。累计公告、实施和实际支付记录不能重复计同一次分红。未知DPS为null，已知零分红为0。

拆股/送转/配股前后EPS、BVPS、DPS和价格必须转为同一股份基础；没有足够依据不硬算。历史PE数据优先使用当时同口径市值/利润，不能将复权价格直接除以未调整历史EPS；价格复权不能自动修复会计口径。

## 6. 敏感性与红线

至少两项有意义的变化：盈利/分红/现金流下修，以及倍数压缩或折现率改变。给变化理由与价格影响，不随折现率机械调整永续增长；不能只复制基准模型换标题。

若减息/利润下修会推翻“重仓安全”，在风险和失效条件中明确。重大分红变动、新财报、业务/股本/资本变化或经营权变化触发重估；不保证固定有效期。full_exit不是亏损止损价，重仓不是建议把账户大部分资金买入。

## 7. 源方法的取舍

借鉴 AI Berkshire 的业务/护城河/治理、三情景、分红覆盖、精确算术与证据纪律；不需要安装该项目。其三情景工具计算未来EPS×退出PE，不可直接当今天价格；其历史r/g阈值不是本Skill默认参数。本Skill不模拟名人发言、不用语录替代论证。
