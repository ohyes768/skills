# 报告模板

交付文件为 analysis.md，数字与来源由绑定渲染。标题含公司、代码与报告年份，正文按以下顺序：

- 核心结论：三到五句，概括业绩、盈利质量、现金负债与风险。
- 主要报表数据：利润表与现金流量表本期/上年同期。
- 关键比率与计算口径：只绑定 computed 指标。
- 经营与三表分析：期初期末余额及本次变化判断。
- 盈利质量与杜邦分解。
- 风险信号：按本次 red_flags 生成，不使用示例默认状态。
- 数据质量评估：可核验范围与勾稽结果。
- 未验证事项与后续观察：接口未覆盖内容及缺失科目。
- 来源与计算说明：东财合并三表、字段与报告期，派生公式。

自由段落不含数字，量化内容放 statement/table。金额明确为元、万元或亿元；百分比和百分点不可混用。程序在 statement 尾部、表格来源列加入接口字段与期间引用。单一接口来源不等于独立数据交叉核对。
