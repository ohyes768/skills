# 黄金推送 · 美联储利率预期（金十数据）

`gold_price_push.py` 的黄金推送以价格和走势为主体，"美联储利率预期"作为末尾精简附录。
数据来自金十利率预测公开接口，由程序做确定性计算，AI 分析只做事实解读，不自行推断利率方向。

## 黄金主体与价格口径

- 消息顺序为国内/国际报价、国内涨跌摘要、黄金分析（走势/辅助因素/后续观察）、技术参考、精简利率附录。
- 实时报价的变化是相对最近已完成交易日收盘，标明基准日期；收盘日涨跌比较最近两个有效收盘，5交易日变化比较最新与第6个倒数有效收盘，标明起止日期。国际现货目前仅有报价，不计算国际涨跌。
- MA5/MA20使用已完成日线收盘。近期20条高低记录完整时展示高低区间，否则展示收盘区间；不足20条标明实际样本数。日线截至日期、区间起止日期和元/克单位均展示。
- 当日/未来、无效、非正或非有限收盘记录不参与计算；同日期一致记录去重，冲突记录剔除并提示。日线超过7自然日，只作历史参考。
- Wilder RSI(14)作为主口径，前14次变化作为种子，从第15次变化开始平滑递推。上涨无损失=100、下跌无收益=0、横盘=50；Simple和第三方只作口径差异对照。
- 实时触及均线不等于收盘突破，超卖不等于见底；当前报价不直接称为支撑阻力。SPDR比较最新两条有效官方持仓记录，注明起止日期；VIX只作市场波动背景。
- 推送利率附录仅展示下次会议及关键比较，未来三次累计利率路径继续保留在完整利率预览中。

布局预览（合成历史日线，无网络、LLM及钉钉发送）：

```bash
python scripts/preview_gold_push.py
```

## 数据来源

| 数据 | 来源 | 说明 |
|------|------|------|
| 利率预期快照 | 金十 `mp-api.jin10.com/api/long-pictures/list`（`category=interestRateForecast`） | 下次会议降息/维持/加息概率、未来三次会议概率加权预期利率 |
| GLD 实物持仓 | SPDR 官方历史文件 `api.spdrgoldshares.com`（US GLD Historical Archive 表，`Tonnes of Gold` 列） | 官方公布吨数，**不再**用总资产÷金价估算 |

## 本地预览（不发消息、不调 LLM）

```bash

python -m gold.fed_cache

```

## 缓存与状态

- 每个北京时间发布日只保留最新有效快照，最多保留 180 天，原子写入。
- 成功获取后 1 小时内复用缓存（`status=cached`），避免高频拉取。
- 获取失败或数据源回退时沿用本地较新缓存（`status=fallback`），**不再判断方向**。
- 快照超过 96 小时视为过期（`status=stale`），仅作历史参考。
- 到达快照内的议息日且数据源未滚动（`status=awaiting_update`），保守停用，不沿用旧概率。
- 概率比较只在**同一会议 + 相同当前目标利率**的不同发布日快照间进行；接口内置的"昨日"列（NOW/1 DAY）日期口径不一致，不使用。

## 限制

- 金十接口为公开小程序接口，无官方文档、无登录，字段结构可能变化；解析失败时栏目降级为"数据暂缺"，不影响金价推送其余部分。
- 后续会议的预期利率是**累计路径**中点，不是该次会议单独加减息的概率。
- `hawkish`/`dovish` 仅表示预期利率上移/下移，对黄金是潜在压力/支撑，不构成涨跌预测。
- XAUUSD 国际现货为可选数据源，失败时显示"暂缺"，不阻断推送。
- 概率保留一位小数，允许每档 0.05 个百分点的舍入误差（概率总和容差随档位数放大）。
