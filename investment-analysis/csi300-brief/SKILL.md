# 沪深300简况

读取 index-trends 只读状态接口，输出2—3句中文概况，通常不超过200字；有数据异常时可追加一句说明。只生成文字，便于调用方展示或投递。

## 获取数据

运行本 skill 附带脚本（Python 3.9+，仅标准库，无需安装依赖）：

```bash
python "<skill目录>/scripts/brief.py"
```

将 `<skill目录>` 替换为本次加载的 SKILL.md 所在目录，不依赖当前工作目录。脚本直接向标准输出写入简短中文概况，默认原样展示，保留数据日期和异常提示，无需再组织请求或重算字段。

默认请求 `https://web.duomi77.cn:9443/api/index-trends/indices/000300/status?model=trailing_10y_weekly`。
可用 `--model since_inception_weekly` 切换上市以来模型，`--timeout 20` 设置正数超时秒数。
用户指定内部或本地部署时使用 `--base-url` 传入 API 前缀，例如：

```bash
python "<skill目录>/scripts/brief.py" --base-url http://localhost:8100/api
```

请求成功且响应有效时退出码为0；HTTP、网络、TLS或响应格式失败时输出一条失败说明并退出1。
有效响应中的数据滞后、缺失或估值失败仍输出带警告的概况并退出0，调用方需保留警告。
离线验证：在 skill 目录运行 `python -m unittest discover -s tests -v`。

- 默认 `model=trailing_10y_weekly`，中文称“近10年周线通道”。用户指定上市以来模型时改为 `since_inception_weekly`，称“上市以来周线通道”。不询问用户选择默认模型。
- 查询只读缓存，不调用刷新、周报任务或 RSS 写入接口，不读取供应商令牌。只有显式传 `--push` 时才向钉钉机器人投递（见下文），默认不发送；定时由调用方负责，本 skill 不创建定时任务。
- 请求超时、非2xx或响应不是有效JSON时，脚本输出“沪深300数据暂时获取失败”及简短原因，停止生成行情概况，不用示例或记忆补值。默认严格校验 TLS，脚本不会自动关闭校验；只有调用方显式传 `--insecure` 才跳过，或传 `--ca-file <证书路径>` 把自签证书/内网 CA 指定为信任根。

## 解读规则

1. **通道与行情**：先检查 `available` 和 `data_status.state`。只有 `available=true` 且相应数值存在时，才使用 `close`、`price_as_of`、`position_pct`、`lower`、`mid`、`upper`。`available=false` 时写“周线通道暂不可用”，按 `reason` 简述原因，但仍独立检查估值。`available=true` 不代表行情新鲜：`data_status.state` 不是 `ok` 或状态缺失时，必须注明行情缓存、数据滞后或状态未确认等实际情况，不称为实时行情。
2. **位置**：`position_pct` 已是百分数，不再乘100。0%对应下轨，100%对应上轨；负值或超过100%保留原值，不裁剪。`region` 映射：`below_channel`→通道下方、`lower`→低位、`middle`→中部、`upper`→高位、`above_channel`→通道上方。区域不明时只报数值，不猜测。通道位置不是PE分位，也不是上涨概率。
3. **估值**：读取 `valuation.pe_ttm`、`valuation.percentile_pct`、`valuation.as_of`、`valuation.target_date`、`valuation.state`、`valuation.reason`。PE保留2位小数，分位保留1位小数，单位分别为“倍”和“%”。分位是理杏仁总市值加权PE-TTM的近10年历史分位，API已换算为0—100，不本地重算。0是有效数值，`null`或字段缺失才表示无数据。只说明历史相对位置，不把分位推导成买卖建议或涨跌预测。
4. **估值状态独立处理**：`ok`可正常描述；`stale`必须写“估值滞后”，可列实际日期及目标日期；`error`有数值时写“估值更新失败，以下为缓存值”，无数值时写“估值暂不可用”；`empty`写“估值暂无数据”；`disabled`写“估值未启用”。对象、状态或单项数值缺失时如实写“状态未确认”或该项暂无数据，不将其解释为0，不把估值故障说成通道故障。
5. **日期**：通道使用最近已收盘交易日的价格投影到周线模型，`projection_week`是该自然周的周一，不是价格日期。PE目标日是最近应当完成的自然周的最后交易日；两者可能不同。分别标明 `price_as_of` 和 `valuation.as_of`，日期不同时不能合称“截至今天”。字段缺失时注明日期未提供。不将进行中周的价格称为已完成周收盘价。

## 输出

默认使用短段落，不输出JSON、表格、长篇分析或接口内部字段名：

“沪深300截至{价格日期}收于{收盘价}点，位于{模型名称}{区域}，通道位置{位置}%，下轨/中轨/上轨为{下轨}/{中轨}/{上轨}点。估值截至{估值日期}，PE-TTM为{PE}倍，近10年分位{分位}%。”

价格与轨道保留2位小数，位置保留1位小数。每个占位值都必须来自本次成功响应；缺项时改写句子，不保留占位符。估值日期不同或任何业务状态异常时，按上述规则修改相应句子。不要为了缩短文字省略异常提示。

以下仅演示语气，全部是虚构数据，执行时不可复用：

> 沪深300截至2026-10-30收于4000.00点，位于近10年周线通道中部，通道位置50.0%，下轨/中轨/上轨为3000.00/4000.00/5000.00点。估值截至2026-10-30，PE-TTM为12.35倍，近10年分位56.6%。

## 推送钉钉（可选）

只有显式传 `--push` 才发送；不传时只打印文本，不触网推送。

```bash
python "<skill目录>/scripts/brief.py" --push
```

配置只认两个键，放在本 skill 目录的 `.env`（`.gitignore` 的 `**/.env` 已排除，勿提交）：

| 键 | 说明 |
|---|---|
| `DINGTALK_WEBHOOK` | 群机器人 Webhook 完整地址（含 access_token）；代码、日志和推送结果都不会打印它 |
| `DINGTALK_KEYWORD` | 机器人安全设置里的自定义关键词，本群为 `ETF`；默认标题「沪深300 ETF 简况 · {价格日期}」已固定包含它 |

- 推送正文使用 Markdown 版：`###` 标题、关键数字加粗、每条异常独立成 `⚠️` 行、结尾一句口径说明；stdout 仍输出纯文本句子，日志与只读调用方不受影响。
- 标题默认「沪深300 ETF 简况 · {price_as_of}」，缺价格日期时用当天日期；`--title` 可覆盖，但覆盖后仍须包含 `DINGTALK_KEYWORD`，否则本地直接拒绝、不发起请求。
- 关键词按原文整串匹配、区分大小写：写成 `etf` 不算命中。
- stdout 只有概况原文；推送结果是一条 JSON 写到 stderr，只读 stdout 的调用方不受影响。
- 退出码：`0` 已发送或 `--dry-run` 通过；`1` 取数失败；`2` 关键词不匹配或未配置 Webhook；`3` 网络异常/超时（可能已送达，先核对再重发）；`4` 钉钉拒绝（token 无效、限流等）。
- `--dry-run` 校验 Webhook 与关键词但不发送，用于首次接线。
- 不做去重：同一份内容重复推送会重复出现，防重由调用方按其时间粒度负责（例如按 `price_as_of` 或交易日）。
- 其他参数：`--env-file`、`--keyword`、`--push-timeout`（默认 10 秒）。
- `--only-today`：价格日期不是北京时间今天时静默跳过，不发消息，stderr 输出 `"status": "skipped"`、退出码 0；节假日与停牌日因此不会重复推送上一交易日的内容。
- 定时：`scripts/cron_daily.sh` 封装了 `--push --insecure --only-today`，日志写本 skill 的 `logs/csi300-brief.log`。数据管线北京时间 16:30 入库，所以按 16:35 跑；服务器时区是 UTC 时 crontab 写 `35 8 * * 1-5`。
- 服务器不信任 `web.duomi77.cn:9443` 的自签证书时取数会失败（`curl` 校验得 0、`-k` 得 200 即属此情况），此时显式加 `--insecure`，或改用 `--ca-file <证书路径>`；默认仍然严格校验。
- 线上定时示例：`python3 scripts/brief.py --push --insecure >> logs/csi300.log 2>> logs/csi300.err`。
