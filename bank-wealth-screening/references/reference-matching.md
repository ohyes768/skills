# 同系列老份额参照（推荐前必做）

新份额（成立 <6 个月）指标是建仓期虚高，**不输出给用户**；推荐理由建立在同系列成立 1 年+ 老份额上。

## 工具选择

| 场景 | 工具 |
|---|---|
| **杭银自营**（首选） | `python3 scripts/hz_ref_match.py <产品名片段\|productCode\|dengjino> [--nav] [--top 5]` —— 自动按同期限+同策略族筛参照，`--nav` 附带滚动窗口业绩 |
| 信银/华夏/南银 + 招行目录 | `python3 scripts/series_ref.py <系列关键字> [--top 5] [--min-days 180] [--online-cmb]`（⚠️ 不含杭银自营） |
| 招行自营老份额搜索 | `m.cmbchina.com/api/financing/product-list` 带 `keyword` 参数可搜全目录 7689 只（`prdName`/`prdCode` 参数无效，只有 `keyword` 生效），按 `beginDate` 排序取最老 |
| 兜底 | 老份额不在任何索引里时，web 搜产品全名找老代码再喂 `nav_stats.py`（例：665593=招睿安悦370天1号、130052A=招睿明裕180天持有2号） |

- **南银 series_ref 报 0 时直接用 `ny_nav_fetch.py` 按代码拉**（增瑞财富牛 Z70021 实测能拉到 58 点净值，series_ref 却报 0）。华夏系同判断：先跑 `hx_fetch.py` 建索引，候选代码在 priority 列表就可用单代码抓取——固收增强周期180天（2119187001，5年老份额）就是这样找回的。
- **杭银自营报"无参照"前必须先跑 `hz_ref_match.py`**，否则一律视为漏查（2026-11-25 实例：添益180天持有、安享优选182天周期型、半年添益全都有多年老份额，series_ref 却报 0）。
- 整个系列查不到 ≥min-days 的份额就明确告知"该系列无业绩可参照、盲买管理人"，不许拿别的线充数。

## "同系列"判定（2026-11-27 修正）

- **招银**：每期新登记编码（`120148A`=Z7001626001284，老份额 `120007A` 是别的码），按 regCode 匹配必然失败，须按**产品线**匹配：添金／添鑫／添利／丰和／鑫鼎／安悦／明裕／明睿／增瑞／增泰…，同产品线内优先取持有期相同的老份额。
- **杭银封闭式：每期一个新 dengjino，dengjino 是"期"级标识不是"系列"级**（例：丰裕固收386天25205期=Z7002225000395、26174期=Z7002226000420，是同一条滚动产品线的相邻两期）。杭银同系列判定 = **产品线名去期号/份额字母后逐字一致 + `licaiqixian` 期限一致 + typeinfo b/c/d 段一致**；括号里的 幸福金桂/稳利低波颐养款/爽盈优选 等是渠道或主题标签，不改变产品线归属。
- **期限必须一致（硬规则）**：不同期限的老份额只能作辅助背景并标注"不同期限线，仅供参考"，**不得进入推荐理由**。反例：给「丰裕固收386天26174期」配「丰裕固收（稳盈）1106天23202期」——同品牌不同期限且 c1≠c2，会把预期抬高约半个百分点。
- **要防的是不同名并行线冒充参照**：丰鸿固收 vs 丰鸿（灵动盈/灵动目标盈）、丰裕固收386天 vs 丰裕固收（稳盈）1106天——名称含括号别名且期限/策略族不同，一律不许作业绩背书；此类线只能作**负面/策略指纹证据**。
- **策略族校验**：同系列不同策略不能互为参照。实测错配：`添金(人民币固收)` 误配 `天添金(美元)`；`增泰日开(固收)` 误配 `增泰全球商品融合／湾区全球优选(商品/全球)`。判定：名称含 美元/欧元/港币 → 外币；含 全球/国际/湾区/环球/商品/QDII → 全球；否则人民币。
- **typeinfo 是策略指纹**：杭银 typeinfo `b5`=含转债/弹性敞口（固收+），同带 b5 的产品线即使标 R2 波动也明显高于纯固收（b2/b3）线；稳健型用户优先纯固收线。
- **风险等级的历史变化**：老份额当年可能风险等级更高（如丰鸿系 2026-06 前份额是 R3，之后才降标 R2），要向用户说明参照与本期不完全对应。

## T 份额查不到 ≠ 无业绩

cfweb 对渠道专属 T 份额返回"查无此代码"，但同一产品的 A/B/C/D 份额查得到（例：招睿增利指南针180天持有期1号，108998T 失败、108998A/C 一次命中 142 点）。报"无参照"前先把代码尾缀换成 A/C/D 各试一次。封闭系列新发期（如增鼎封闭11号仅成立 7 天）才算真无参照——用官网详情页/同花顺搜索结果交叉确认最老份额的成立日期再下结论。

## 业绩口径与门槛

`nav_stats.py` 输出成立年化（复利）+ 滚动窗口（近30/90/180天年化、区间回撤）。注意：

- **起点净值≠1 的份额（溢价/折价 B/C 款）成立年化含起点偏差**（脚本会打 ⚠），跨份额对比以滚动窗口为准。
- **以滚动窗口为预期锚，成立年化只作背景**：
  - 反例：杭银添益180天持有期老份额成立年化 +2.2%~+3.1%，但近30天 -2.2%~-2.5%、近90/180天仅 +0.3%~+0.7%（债市调整）→ 只报成立年化会严重误导，预期须按滚动窗口口径并标注"成立年化含前期牛市贡献"。
  - 正例：丰裕固收老份额两口径一致（+2.7%~+3.0% vs +3.1~3.3%）→ 可按近期口径给预期。
- 现金管理类（净值恒 1）不适用滚动窗口，按七日年化口径（见 data-sources.md 万份收益章节）。
- 封闭式产品 Sharpe 异常高（净值几乎无波动，如兴银稳利恒盈 SR=14.6）——向用户说明该指标不适用。

| 指标 | 最低门槛 | 勉强可信 |
|---|---|---|
| 成立年化 | 3个月 | 6个月+ |
| 最大回撤 | 6个月 | 1年 |
| Sharpe | 1年 | 2年+ |
