# Commit Message 模板

根据改动类型选用，替换 `<>` 中的占位符。

## feat — 新功能

```
feat(<模块>): 添加<功能描述>

- 实现<具体功能点1>
- 实现<具体功能点2>
- 添加<配置/参数>
```

## fix — 修复 Bug

```
fix(<模块>): 修复<问题描述>

- 修复<bug 具体表现>
- 根本原因：<原因分析>
- 解决方案：<解决方法>
```

## docs — 文档更新

```
docs(<文档名>): 更新<更新内容>

- 更新<章节1>：<具体变更>
- 更新<章节2>：<具体变更>
- 补充<新增内容>
```

## refactor — 重构

```
refactor(<模块>): <重构目标>

- 提取<方法/类>：<说明>
- 简化<逻辑>：<说明>
- 优化<结构>：<说明>
```

## perf — 性能优化

```
perf(<模块>): 优化<目标>

- <优化手段1>
- <预期效果>
```

## test — 测试

```
test(<模块>): 添加<测试范围>

- 覆盖<场景1>
- 覆盖<场景2>
```

## chore — 杂项

```
chore(<范围>): <变动说明>

- <具体变更>
```
