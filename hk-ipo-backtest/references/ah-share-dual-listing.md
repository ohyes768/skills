# A+H 双重上市票回测参考

港股新发里相当一部分是 **A 股已上市 + H 股新发** 的双重上市票（A+H）。A+H 票的回测研究路径与"纯 H 股新发"有几条重要差异，本文记录可复用步骤、字段差异、AH 折价作为预测因子的实战用法。

## 适用判定

回测目标 IPO 满足以下任一条件即按 A+H 路径处理：

1. **同主体代码可查**：A 股代码（如 300223、688xxx、600xxx、601xxx）与 H 股代码（如 03223）在公开媒体至少一处被同时引用（如招股书"本公司 A 股股票于 xx 年在 xx 交易所上市"）。
2. **招股书披露 A 股历史业绩**：H 股招股章程"业务"章节引用 A 股年报 / 半年报数据。
3. **AH 折价数据可查**：同花顺 / 雪球 / 东方财富 AH 比价页能查到该股的 A 股价格 + H 股招股价上限。

不满足的（如纯 H 股新发、A 股母公司通过分拆子公司赴港上市、母公司本身未在 A 股 IPO）按普通 H 股新发处理。

## 字段差异（A+H vs 纯 H 股新发）

| 字段 | 纯 H 股新发 | A+H 双重新发 | 优先级 |
|---|---|---|---|
| 财务三表（营收 / 净利 / 现金流）| HKEX 招股书 PDF（通常抓不到 → PITFALL #2）| **A 股年报 / 一季报（巨潮 / 东方财富 / 同花顺 SSR 可达）** | A+H 优先 A 股源 |
| 实际控制人 / 控股股东 | 招股章程（章节简略）| **A 股年报"实际控制人"章节（完整名单 + 持股比例）** | A+H 优先 A 股源 |
| 主要机构 / 产业股东 | 招股章程「主要股东」+ 基石名单 | A 股年报「前十大股东」+ H 股基石 | A+H 两者并取 |
| 业务模式 / 客户结构 | 招股章程（中等详尽）| A+H 通常更详尽（A 股年报披露多年客户结构）| 同等 |
| 估值 | 招股价 / 招股 PE / 上市后 PE | **A 股 PE + AH 折价率 + H 股发行 PE** | A+H 多一维 |
| 上市前股价信号 | 无 | **A 股截止点前最后一日收盘价 × 汇率 vs H 股招股价上限 → AH 折价** | A+H 专属 |

## 数据源优先级（A+H 票专用）

| 数据类别 | 主源 | 备源 | 抓取失败 fallback |
|---|---|---|---|
| A 股最新年报 / 一季报 | 巨潮 (cninfo.com.cn) 公告页 | 东方财富 datacenter / 同花顺 F10 | 雪球文章（注意日期）|
| A 股实际控制人 | A 股年报「公司基本情况」| 雪球年报整理 | 公司投资者关系页 / 招股章程 |
| A 股截止点前最后一日收盘 | 同花顺 / 东方财富 K 线 | 雪球历史报价 | `web_search "<公司名> <日期> 收盘"` |
| A 股价格 → HKD 折算汇率 | 央行中间价 | 雪球当日折算 / 招股章程"汇率假设" | 中国银行外汇牌价 |
| H 股招股价上限 | HKEX 招股章程（公开日 = 招股首日）| jisilu `price_range` | 智通财经 / 财富号 |
| H 股基石名单 | HKEX 招股章程（完整）| jisilu / 雪球 / 财富号 招股首日报道（部分）| — |

## AH 折价计算与解读

**计算公式**（截止点前最后 A 股交易日）：

```
A 股折算 HKD = A 股收盘价 × (HKD/RMB 中间价)
AH 折价率 = (1 - H 股招股价上限 / A 股折算 HKD) × 100%
```

**区间解读**（基于 2024–2026 实战样本，仅供参考）：

| 折价率 | 开盘方向预期 | 实战案例（截止点前推算）|
|---|---|---|
| < 20% | 开盘承压（H 股定价偏贵 → 开盘可能下移）| — |
| 20–30% | 开盘小幅承压或平开 | — |
| 30–50% | **开盘保护带**（折价吸收 A 股短期波动）| 03223 君正股份 43.17%（2026-08-19）|
| 50–70% | 开盘可能高开（A 股估值已透支，H 股定价偏低）| — |
| > 70% | 极端情况（通常 A 股高估值或 H 股定价异常低）| — |

**关键注意**：
- AH 折价是**截止点前可证**的预测因子（截止点前最后 A 股交易日收盘价 + 招股章程公开的招股价上限都在截止点前可查）。
- 折价率本身**不是因果**——A 股估值高 ≠ H 股必然高开；但折价率**是方向保护因子**：折价越深，开盘后向 A 股靠拢的下行空间越大，但开盘首日的下行动能越小。
- 验证阶段不要被"AH 折价"骗到忘记看 **A 股在 H 股上市前后的走势**：若 A 股在 H 股上市前 1 周大涨 / 大跌，开盘方向会被该短期资金面冲击主导。

## 预测输入重建（A+H 截止点前可证字段）

```yaml
A 股最新年报:
  source: A 股巨潮 / 东方财富 / 同花顺
  deadline_proof: 发布日期 ≤ 截止点（年报通常 3-4 月披露，远早于招股期）
  fields: [营收, 归母净利, 经营现金流, ROE, 毛利率]
A 股最新一季报 / 业绩快报:
  source: A 股巨潮 / 东方财富 / 同花顺
  deadline_proof: 一季报 4 月底披露，业绩快报 7-8 月披露
  fields: [Q1 营收, Q1 归母净利, YoY 增速]
A 股截止点前最后一日收盘:
  source: 同花顺 / 东方财富 K 线
  deadline_proof: 收盘价本身就是 T 日数据，T ≤ 截止点 → 必然可证
  fields: [A 股收盘价, 折算 HKD, AH 折价率]
实控人 / 主要股东:
  source: A 股年报「公司基本情况」+「前十大股东」
  deadline_proof: 年报披露日 ≤ 截止点
  fields: [实控人姓名, 持股比例, 一致行动人, 前十大股东]
H 股招股条款:
  source: HKEX 招股章程
  deadline_proof: 招股章程公开日 = 招股首日（通常 ≤ 截止点 -1 自然日）
  fields: [招股价上限, 公开发售比例, 总发售股数, 每手, 入场费, 基石名单]
H 股基石:
  source: 招股章程 + 招股首日媒体（智通 / 财富号 / 雪球）
  deadline_proof: 招股首日 ≥ 截止点 -3 自然日
  fields: [基石数量, 占比, 名单]
Sponsor:
  source: 招股章程
  deadline_proof: 招股章程公开日 ≤ 截止点
```

## 验证阶段字段（A+H 验证时额外记录）

| 字段 | 来源 | 注意 |
|---|---|---|
| H 股上市当日 A 股表现 | A 股 K 线 / 东方财富 | 与 H 股首日表现对比 — A 股大跌未必传导 H 股（折价保护层）|
| H 股上市后 5 个交易日 A 股表现 | 同上 | 看 A 股是否向 H 股定价靠拢（A+H 收敛速度）|
| H 股首日换手率 | futu / 港交所披露易 | 高换手 = 解禁抛压 + 基石护盘力量对比 |
| H 股首日收市后 AH 折价率 | 自行计算 | 与截止点前 AH 折价率比较 → 看定价合理性 |

## 实战模板（03223 君正股份 2026-08-25 案例）

```yaml
案例: 君正股份 (03223.HK, A 股 300223.SZ)
案例日: 2026-08-25
招股期: 2026-08-17 至 2026-08-20 16:00 HKT
截止点: 2026-08-19 23:59:59 HKT

A 股最新年报 (2025):
  source: 同花顺 F10 / 智通财经 2026-03-27
  deadline_proof: 2026-03-27 < 2026-08-19 ✓
  data:
    营收: 47.41 亿元 (+12.54% YoY)
    归母净利: 3.76 亿元 (+2.74% YoY)
    Q4 营收: 13.05 亿元 (+28.98% YoY)
    Q4 归母净利: 1.2 亿元 (+95.01% YoY)

A 股最新一季报 (2026Q1):
  source: 界面新闻 / 北京君正公告
  deadline_proof: 2026-04 < 2026-08-19 ✓
  data:
    营收: 15.60 亿元 (+47.12% YoY)
    归母净利: 3.19 亿元 (+331.61% YoY)

A 股截止点前最后收盘 (2026-08-15 周五):
  source: 雪球长文 2026-08-17 二次引用
  deadline_proof: 2026-08-15 < 2026-08-19 ✓
  data:
    A 股收盘: 155.39 元 RMB
    折算 HKD: ~180.92 (1 RMB ≈ 1.1644 HKD)
    AH 折价率: ~43.17%

实控人:
  source: A 股 2024 年报（雪球整理 2026-02-02）+ 证券日报 2026-03-24
  deadline_proof: 年报披露日 < 截止点 ✓
  data:
    实控人: 刘强、李杰 (一致行动人)
    持股: 刘强 9.06% + 李杰 3.89% = 12.95%
    背景: 清华大学 + 中科院博士嵌入式 CPU 领域

预测结论 (截止点冻结):
  暗盘方向: 下跌 (公开发行 10% 解禁 + A 股估值偏高)
  开盘方向: 持平 (43% 折价提供下行保护 + 热度极热)
  收盘方向: 边界持平（持平 / 弱下跌 -0.05%）
  置信度: 中 (受控事后重建)

真实结果 (验证阶段解锁):
  最终定价: 100.00 HKD (区间下移 -2.7%)
  暗盘: -0.25%
  开盘: 100.00 平开 (持平命中)
  盘中最低: 99.50 (-0.50%)
  收盘: 99.95 (-0.05%, 持平边界)
  A 股 8/25 表现: -10.15% (折价保护层吸收)
  命中结论: 部分命中 (开盘 ✓ / 暗盘 ✓ / 收盘边界)

复盘:
  折价保护层厚度 (~43%) > 解禁抛压 + A 股当日 -10.15% 跌幅冲击
  → 收盘 -0.05% 而非预测的"弱下跌 -1% 量级"
  → 模型对"折价 vs 解禁抛压"的相对权重需进一步校准
```

## 反例 / 注意点

1. **A 股截止点前最后收盘 ≠ A 股招股前最后收盘**：若 A 股 8/15 是周五（最后交易日），截止点是周三，则 A 股 8/15 收盘可证；若 A 股在截止点前一周有停牌 / 涨跌停限制，需明确标注数据时点。
2. **汇率假设**：HKD/RMB 用央行中间价（每日 9:15 公布，截止点前一日中间价即可查）；不要用现汇买入价 / 现钞卖出价等偏离中间价的口径。
3. **A 股年报披露日 vs 截止点**：A 股年报通常 3-4 月披露，远早于任何港股招股期；但若 A 股 8 月刚披露半年报（实际 A 股半年报通常 8 月底），可能晚于截止点（招股期 8 月初）→ 半年报不能用，只能用最新年报。
4. **HKEX 招股章程"业绩记录期"vs A 股最新报告期**：H 股招股章程通常要求最近 3 个完整财年 + 最近 1 期（如 2024 / 2025 全年 + 2026H1）；A 股年报披露通常更早，但仅 1 个完整年度 + 1 期。两者数据**会重叠但不重合**，不要互相覆盖——招股章程的多年财务 + A 股最新一季报是互补关系。
5. **AH 折价 > 70% 的极端情况**：通常意味着 A 股估值已严重透支（半导体 / AI 概念炒作末期），H 股开盘高开后大概率回落，A 股在 H 股上市后向 H 股定价靠拢。此类情况下"开盘方向持平 / 上涨"是陷阱，要标注"折价深但 A 股估值已透支"的额外风险。
