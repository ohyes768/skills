## 可复用结论（**新增 PITFALL #35**）

1. **发行价 = 区间下限 → 平开 0.00% 不应自动判为"持平"**。回测验证阶段判断"开盘方向"时，必须先确认 `issue_price == price_range_lower_bound`：
   - 开盘 0.00% + 发行价 = 区间下限 → 定价博弈中性结果，开盘无方向信息，权重降到 ~0.3
   - 开盘 0.00% + 发行价 = 区间上限 → 罕见（极强发行人对定价信心），权重 ~0.3
   - 开盘 0.00% + 发行价 = 区间中点 → 常见（定价博弈中间），权重 ~0.3
   - 开盘 ≠ 发行价（跳空 ±X%）→ 权重 ~1.0，按默认规则判定
2. **综合结论权重调整（开盘 vs 收盘 vs 暗盘）**：
   - 默认权重：开盘 1/3 + 收盘 1/3 + 暗盘 1/3
   - 当发行价 = 区间下限时：开盘 0.3 + 收盘 0.5 + 暗盘 0.2（开盘 0.00% 不扣命中分）
3. **下沿定价的方向调节因子**：
   - 同样是"发行价 = 区间下限"，**方向完全相反**取决于产业股东背书 / 一票否决信号数：
     - **PITFALL #13 反炒案例**（03231 优地机器人）：18C + 阿里系 + 商汤 + 科大讯飞 + 4 项全满足 → 大涨 +155.78%
     - **本案例**（06727 星环科技）：18C + **4+ 类一票否决** + **无大型产业股东** → 大跌 -6.94%
