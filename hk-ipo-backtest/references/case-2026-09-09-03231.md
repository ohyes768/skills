## 可复用结论（**新增 PITFALL #28**）

1. **18C 章"亏损反炒"是模型预测盲区，需新增护城河/市场信号识别**：当候选 IPO 同时满足以下 4 项时，应额外加分或升级市场信号档：
   - 18C 章 / 第 18A 章 / 未盈利标的（港交所特专科技章节）
   - 流通盘小（总市值 < 100 亿港元 或 公开发售 < 1 亿港元）
   - 大型产业股东背书（阿里系 / 腾讯系 / 商汤 / 科大讯飞 / 美团 / 京东 等 ≥1 家战略股东）
   - 招股定价最终落在区间下限
   - **典型反例**：02261 拿森科技（同样 18C 章 + 流通盘小 + 单一产业股东，首日大涨）+ 03231 优地机器人（本案例，4 项全部满足，+155.78%）
2. **客户集中度对 18C/未盈利标的 = 商业模式稳定信号，而非风险**：头部客户绑定（阿里、京东、美团 等）反而强化了商业模式的稳定性，应单独区分打分。
3. **招股定价落在区间下限 = 首日跳空空间加分**：原评分"估值"维度未将"定价博弈空间"作为加分项；可考虑加入"定价 vs 区间下沿的距离"指标，距下沿 < 5% 给估值分 +2~+3。
4. **证监会备案质询的"利空出尽"效应**：备案质询在招股聆讯前公告 → 招股期内充分回应 → 首日市场倾向于"已解决 = 不再计价"。原评分扣减 -8 偏重，可考虑降至 -3~-5。
5. **数据源稳定性矩阵应在每份 backtest 报告的 §4 真实结果中显式落地**：本次 sina hq + jisilu 共 2 源交叉，jisilu +153.29% vs sina +155.78% 差 2.49pp 必须显式标注。
6. **截止点前快照的可复用验证规则（PITFALL #11）4 项 checklist 本次全部通过**：hk-ipo-daily-2026-09-03-03231.md 是有效截止点快照，可直接引用其评分（37 C）与方向预测（下跌或破发）。
